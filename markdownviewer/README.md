# 📝 マークダウンビューアー

リアルタイムでマークダウンをプレビューできる、シンプルで使いやすいマークダウンビューアーです。

## ✨ 主な機能

### 現在実装されている機能

1. **リアルタイムプレビュー**
   - 左側のテキストエリアにマークダウンを入力すると、右側に即座にレンダリング結果が表示されます
   - プレーンテキストとレンダリング済みHTMLを同時に確認できます
   - 左右のパネルが独立してスクロール可能

2. **マークダウン記法のフルサポート**
   - 見出し（H1〜H6）
   - 太字、イタリック、取り消し線
   - リスト（番号付き・番号なし）
   - リンクと画像
   - インラインコードとコードブロック
   - シンタックスハイライト（Highlight.js使用）
   - 引用
   - 水平線
   - テーブル

3. **ファイル操作機能**
   - **ファイルを開く**: txt/mdファイルをボタンから選択して読み込み
   - **ドラッグ&ドロップ**: テキストエリアにファイルをドラッグ&ドロップして読み込み
   - **ダウンロード**: マークダウンファイルとしてダウンロード（デフォルトファイル名: `yyyymmdd_markdown.md`）
   - ファイルサイズ制限: 10MB以下

4. **便利な機能**
   - **文字数カウント**: リアルタイムで入力文字数を表示
   - **自動保存**: 入力内容をローカルストレージに自動保存（ページを閉じても内容が保持されます）
   - **クリアボタン**: 確認ダイアログ付きで内容を一括削除
   - **コピーボタン**: マークダウンテキストをクリップボードにコピー
   - **全画面プレビュー**: プレビュー部分を全画面表示（ESCキーで解除）

5. **カスタマイズ可能なレイアウト**
   - 左右のパネル幅を自由に調整可能（中央の仕切りをドラッグ）
   - デフォルトは50:50の分割表示
   - リサイズ範囲: 20%〜80%

6. **レスポンシブデザイン**
   - デスクトップでは左右2分割表示
   - モバイルでは上下2分割表示に自動切り替え

7. **快適な編集環境**
   - カスタムスクロールバー
   - モダンなUIデザイン
   - スムーズなアニメーション
   - ドラッグ中の視覚的フィードバック

## 🚀 使い方

1. `index.html` をブラウザで開きます
2. 以下のいずれかの方法でマークダウンを入力します：
   - 左側のテキストエリアに直接入力または貼り付け
   - 「📁 ファイルを開く」ボタンからtxt/mdファイルを選択
   - テキストエリアにtxt/mdファイルをドラッグ&ドロップ
3. 右側に自動的にレンダリング結果が表示されます
4. 中央の仕切りをドラッグして、左右のパネル幅を調整できます

### ボタン機能

- **📁 ファイルを開く**: txt/mdファイルを選択して読み込みます
- **クリア**: 入力内容を全て削除します（確認ダイアログ付き）
- **コピー**: マークダウンテキストをクリップボードにコピーします
- **ダウンロード**: マークダウンファイル（.md）としてダウンロードします
  - ファイル名は自動的に `yyyymmdd_markdown.md` 形式で生成されます
  - 例: `20260129_markdown.md`
- **全画面アイコン**: プレビューを全画面表示します（ESCキーで解除）

### ドラッグ&ドロップ機能

- txt/mdファイルを左側のテキストエリアにドラッグ&ドロップすると自動的に読み込まれます
- ドラッグ中はテキストエリアが薄い青紫色にハイライトされます
- 読み込み成功時は画面右上に通知が表示されます

## 🛠️ 使用技術

- **HTML5**: セマンティックな構造
- **CSS3**: モダンなスタイリング、Flexboxレイアウト、レスポンシブデザイン
- **JavaScript (ES6+)**: クラスベース設計、FileReader API、ドラッグ&ドロップAPI
- **Marked.js (v11.1.1)**: マークダウンパーサー（GitHub Flavored Markdown対応）
- **Highlight.js (v11.9.0)**: コードブロックのシンタックスハイライト
