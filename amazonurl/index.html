🔗 Amazon URL クリーナー

長いAmazonリンクをシンプルなURLに変換

✓ コピーしました！

使い方

  1. Amazonの商品ページから長いURLをコピー
  2. 上のテキストエリアに貼り付け
  3. 「変換する」ボタンをクリック
  4. シンプルなURLが表示されるので「コピー」ボタンでクリップボードにコピー

対応URL例

  • amazon.co.jp (日本)
  • amazon.com (アメリカ)
  • amazon.de, amazon.fr, amazon.co.uk など

変換前:

https://www.amazon.co.jp/dp/B08X6PQXX8/ref=sr_1_1?keywords=...

変換後:

https://www.amazon.co.jp/dp/B08X6PQXX8

トラッキングパラメータとアフィリエイトタグを削除して、クリーンなURLを生成します
