# Amazon URL クリーナー

シンプルで使いやすいAmazon商品URLクリーナーです。長いアフィリエイトリンクやトラッキングパラメータを削除して、クリーンな商品URLに変換します。

> このアプリは「Webアプリ集」プロジェクトの一部として統合されています。[プロジェクト全体のドキュメント](../README.md)もご覧ください。

## 🌟 主な機能

### 現在実装済みの機能
- ✅ Amazon商品URLの入力と検証
- ✅ トラッキングパラメータの削除
- ✅ アフィリエイトタグの削除
- ✅ シンプルな`/dp/商品ID`形式のURLへ変換
- ✅ ワンクリックでクリップボードにコピー
- ✅ コピー成功時の視覚的フィードバック
- ✅ エラーハンドリングと分かりやすいエラーメッセージ
- ✅ レスポンシブデザイン（PC・タブレット・スマホ対応）
- ✅ 複数のAmazonドメイン対応（.co.jp, .com, .de, .fr, .co.ukなど）

## 📋 使い方

1. **URLを貼り付け**: Amazon商品ページから長いURLをコピーして、テキストエリアに貼り付けます
2. **変換ボタンをクリック**: 「変換する」ボタンを押すと、クリーンなURLに変換されます
3. **コピー**: 「コピー」ボタンでクリップボードに変換後のURLをコピーできます

### 対応しているURL形式
- `https://www.amazon.co.jp/dp/B08X6PQXX8/...`
- `https://www.amazon.co.jp/gp/product/B08X6PQXX8/...`
- `https://www.amazon.com/product/B08X6PQXX8/...`
- その他のトラッキングパラメータ付きURL

### 変換例
**変換前:**
```
https://www.amazon.co.jp/dp/B08X6PQXX8/ref=sr_1_1?keywords=example&qid=1234567890&sr=8-1
```

**変換後:**
```
https://www.amazon.co.jp/dp/B08X6PQXX8
```

## 📂 ファイル詳細

### index.html
- 共通スタイル（`shared.css`）を先に読み込み
- アプリ固有スタイル（`style.css`）を後で読み込み
- 共通ユーティリティ（`utils.js`）を先に読み込み
- メイン機能（`cleaner.js`）を後で読み込み

### css/style.css
- 共通スタイルを再定義せず、アプリ固有のスタイルのみ記述
- CSS変数を活用して統一感を保持
- レスポンシブデザインの微調整

### js/cleaner.js
- `AmazonUrlCleaner`クラスで全機能を実装
- `AppUtils`の共通関数を活用
- イベント駆動型の設計
- 商品ID抽出ロジックの実装

## 🔒 プライバシーとセキュリティ

- **クライアントサイド処理**: すべての変換はブラウザ内で完結
- **サーバー送信なし**: URLはどこにも送信されない
- **オフライン動作**: インターネット接続不要で動作
- **入力検証**: URLの妥当性を厳密にチェック
