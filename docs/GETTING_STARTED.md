## 🖥️ システム要件

### 必須環境
- **モダンWebブラウザ**（以下のいずれか）
  - Google Chrome 90+
  - Firefox 88+
  - Safari 14+
  - Microsoft Edge 90+

### 推奨環境
- **OS**: Windows 10/11, macOS 10.15+, Linux
- **画面解像度**: 1280x720以上
- **インターネット接続**: 初回読み込み時のみ必要（その後はオフラインで動作）

## 📥 インストール

このプロジェクトはGitリポジトリではなく、ビルドやパッケージマネージャーも使用しません。フォルダをそのまま使うだけで動作します。

### 方法1: ブラウザで直接開く（推奨）

- `index.html` をダブルクリック
- または、ブラウザにドラッグ&ドロップ

### 方法2: 簡易サーバーで起動（開発時向け）

```bash
# Python 3を使用
python -m http.server 8000

# ブラウザで開く
# http://localhost:8000
```

## 🎯 基本的な使い方

### 1. ポータルページ

`index.html` を開くと、すべてのアプリが一覧表示されます。

### 2. アプリの起動

- アプリカードをクリックして起動
- 各アプリは独立して動作
- ブラウザのタブで複数アプリを同時使用可能

### 3. データの自動保存

ほとんどのアプリは、入力したデータを**自動的にローカルストレージに保存**します。

- 📝 ブラウザを閉じてもデータは保持されます
- 🔄 次回起動時に自動的に復元されます
- 🗑️ データの削除は各アプリの「クリア」ボタンで実行

## 📱 各アプリの起動方法

### ブラウザメモ帳

```
ポータル → Notepad → ブラウザメモ帳
```

**機能:**
- タイトルと本文を入力
- リアルタイム自動保存
- 文字数カウント表示

### カウントダウンタイマー

```
ポータル → プレゼンツール → カウントダウンタイマー
```

**使い方:**
1. 終了時刻を入力（例: 15:30）または分数を指定
2. 「開始」ボタンをクリック
3. 全画面表示で大きく表示

### ランダム抽選ルーレット

```
ポータル → 参加者管理 → ランダム抽選ルーレット
```

**使い方:**
1. 各グループの入力欄に参加者名を入力
2. 「スタート」ボタンをクリックすると番号が高速で回転表示される
3. 「ストップ」ボタンをクリックすると段階的に減速し、約5秒後に番号が確定

## 💾 データの保存について

### ローカルストレージ

すべてのデータは**ブラウザのローカルストレージ**に保存されます。

**特徴:**
- ✅ サーバーに送信されない（プライバシー保護）
- ✅ オフラインで動作
- ✅ 容量制限: 約5-10MB（ブラウザによる）

**注意:**
- ⚠️ ブラウザのキャッシュをクリアするとデータが消えます
- ⚠️ プライベートブラウジングモードでは保存されません
- ⚠️ 別のブラウザでは共有されません

### データのバックアップ

重要なデータは、アプリ内のエクスポート機能でバックアップしてください。

```
各アプリ → メニュー → エクスポート → テキストファイルで保存
```

## 🔧 トラブルシューティング

### アプリが起動しない

**問題**: ページが真っ白になる

**解決策:**
1. ブラウザのコンソールを開く（F12キー）
2. エラーメッセージを確認
3. ページをリロード（Ctrl+R / Cmd+R）
4. ブラウザのキャッシュをクリア

### データが保存されない

**問題**: 入力したデータが次回起動時に消える

**解決策:**
1. プライベートブラウジングモードではないか確認
2. ブラウザの設定でローカルストレージが有効か確認
3. 容量制限に達していないか確認
   - Chrome: `chrome://settings/content/all`
   - Firefox: `about:preferences#privacy`

### 表示が崩れる

**問題**: レイアウトがおかしい

**解決策:**
1. ブラウザを最新版に更新
2. ズームレベルを100%に設定
3. ページをリロード
4. 別のブラウザで試す

### ファイルが開けない

**問題**: `index.html` をダブルクリックしても開かない

**解決策:**
```bash
# 右クリック → プログラムから開く → ブラウザを選択
```

**または:**
```bash
# ブラウザを起動してから、ファイルをドラッグ&ドロップ
```
