## 🌟 一般的な質問

### Q1: このプロジェクトは何ですか？

**A:** 日常業務やプレゼンテーション、会議などで役立つWebアプリケーションのコレクションです。ブラウザだけで動作し、サーバーやインストールは不要です。

---

### Q2: 無料で使えますか？

**A:** はい、完全に無料で使用できます。

---

### Q3: オンラインで使用する必要がありますか？

**A:** いいえ、初回読み込み後はオフラインで動作します。すべてのデータはローカルに保存されます。

---

### Q4: 対応ブラウザは？

**A:** 以下のモダンブラウザをサポートしています:
- Chrome 90+
- Firefox 88+
- Safari 14+
- Edge 90+

---

### Q5: スマートフォンやタブレットでも使えますか?

**A:** はい、レスポンシブデザインで、PC、タブレット、スマートフォンすべてに対応しています。

## 💻 インストールと起動

### Q6: インストール方法は？

**A:** このプロジェクトはGitリポジトリではなく、ビルドやインストール作業も不要です。フォルダをそのまま保存し、`index.html` を開くだけで使用できます。

詳細は [Getting Started](GETTING_STARTED.md) をご覧ください。

---

### Q7: Webサーバーは必要ですか？

**A:** 基本的には不要です。`index.html` をダブルクリックするだけで使用できます。

ただし、開発する場合は、以下のようなローカルサーバーを使用することをおすすめします:

```bash
# Python
python -m http.server 8000

# Node.js
npx http-server -p 8000
```

---

### Q8: ダウンロードせずにオンラインで使えますか？

**A:** 現在、公開ホスティングは行っていません。フォルダを取得してローカルで開いてご利用ください。

---

## 💾 データと保存

### Q9: データはどこに保存されますか？

**A:** すべてのデータは**ブラウザのLocalStorage**に保存されます。サーバーには一切送信されません。

---

### Q10: データは永続的に保存されますか？

**A:** はい、ブラウザのキャッシュをクリアしない限り、データは保持されます。

---

### Q11: データをバックアップできますか？

**A:** はい、各アプリにはエクスポート機能があります（実装状況はアプリによります）。

また、以下のスクリプトでLocalStorageの内容を手動でバックアップできます:

```javascript
// ブラウザのコンソールで実行
const backup = {};
for (let i = 0; i < localStorage.length; i++) {
    const key = localStorage.key(i);
    backup[key] = localStorage.getItem(key);
}
console.log(JSON.stringify(backup, null, 2));
// コピーしてテキストファイルに保存
```

---

### Q12: 別のブラウザでデータを共有できますか？

**A:** デフォルトでは共有できません。LocalStorageはブラウザごとに独立しています。

データを移行するには:
1. 元のブラウザでデータをエクスポート
2. 新しいブラウザでインポート

---

### Q13: プライベートブラウジングモードで使えますか？

**A:** 動作しますが、データは保存されません。プライベートモードを終了すると、すべてのデータが消去されます。

---

### Q14: データの容量制限はありますか？

**A:** LocalStorageの容量はブラウザによって異なりますが、一般的に5-10MBです。テキストデータであれば十分な容量です。

---

## 🔧 トラブルシューティング

### Q15: アプリが起動しません

**原因と対策:**

1. **ブラウザが古い**
   - 最新版にアップデート

2. **JavaScriptが無効**
   - ブラウザの設定でJavaScriptを有効化

3. **ファイルパスの問題**
   - `index.html` が正しい位置にあるか確認
   - すべてのファイルが展開されているか確認

4. **コンソールエラーの確認**
   - F12キーを押してコンソールを開く
   - エラーメッセージを確認

---

### Q16: データが保存されません

**原因と対策:**

1. **プライベートモード**
   - 通常モードで使用

2. **LocalStorageが無効**
   - ブラウザの設定を確認
   - Chrome: `chrome://settings/content/cookies`
   - Firefox: `about:preferences#privacy`

3. **容量超過**
   - 不要なデータを削除
   - 他のサイトのLocalStorageをクリア

---

### Q17: 表示が崩れています

**原因と対策:**

1. **ブラウザの互換性**
   - サポート対象のブラウザか確認
   - 最新版にアップデート

2. **ズーム設定**
   - ブラウザのズームを100%に設定

3. **CSSファイルが読み込めない**
   - ファイル構造を確認
   - コンソールで404エラーを確認

---

### Q18: 文字化けします

**原因と対策:**

1. **文字コードの問題**
   - HTMLファイルの文字コードがUTF-8か確認
   ```html
   <meta charset="UTF-8">
   ```

2. **ブラウザの設定**
   - ブラウザの文字エンコーディングを確認

---

## 👨‍💻 カスタマイズと開発

### Q19: 自分でアプリを追加できますか？

**A:** はい、可能です！詳細は [Development Guide](DEVELOPMENT.md) をご覧ください。

基本的な手順:
1. アプリディレクトリを作成
2. `js/config.js` に登録
3. HTML/CSS/JSを実装

---

### Q20: デザインをカスタマイズできますか？

**A:** はい、以下のファイルを編集してください:

- **共通スタイル**: `css/shared.css`
- **ポータル**: `css/style.css`
- **各アプリ**: `[app]/css/style.css`

CSS変数を使用すると簡単にカスタマイズできます:

```css
:root {
    --primary-color: #007bff;  /* メインカラー */
    --secondary-color: #6c757d;
    --background-color: #f8f9fa;
}
```

---

### Q21: 既存のアプリを改造できますか？

**A:** はい、各アプリは独立しているため、自由に改造できます。

ただし、以下を推奨します:
1. 元のファイルをバックアップ
2. Gitで変更を管理
3. カスタマイズ内容を文書化

---

### Q22: TypeScriptで書けますか？

**A:** 現在はVanilla JavaScriptで実装されており、ビルドステップを持たない軽量設計を方針としているため、TypeScript移行の予定はありません。ご自身の環境で移行して使うことは可能です。

---

### Q23: フレームワーク（React、Vueなど）を使えますか？

**A:** 可能ですが、このプロジェクトはフレームワーク不要の軽量設計を目指しています。

フレームワークを使用したい場合は、別プロジェクトとして構築することをおすすめします。

---

### Q24: テストはありますか？

**A:** 現在、自動テストはありません。ビルドツールを使わない方針のため、当面はブラウザでの手動確認が動作確認の中心になります。

---

### Q25: コントリビュートできますか？

**A:** 現時点ではGitリポジトリ・公開Issueトラッカーを運用していない個人利用のツール集です。将来Git管理・公開する場合の想定フローは [Contributing Guide](CONTRIBUTING.md) にまとめています。
