## メモ・ドキュメント

### 📝 ブラウザメモ帳
**ディレクトリ**: `simplenotepad/`

シンプルで使いやすいブラウザベースのメモ帳アプリケーション。

#### 主な機能
- タイトルとテキストの入力
- タイムスタンプ挿入（yyyy/mm/dd hh:mm形式）
- 文字数・行数カウント表示
- クリップボードにコピー
- .txt / .md 形式でダウンロード
- ファイル名自動生成（日付_タイトル形式）
- ローカルストレージによる自動保存
- レスポンシブデザイン

#### 使い方
1. タイトルとテキストを入力
2. 必要に応じてタイムスタンプボタンで日時を挿入
3. コピーまたはダウンロードで保存

詳細: [README](../simplenotepad/README.md)

### 📄 4分割メモ帳
**ディレクトリ**: `fournotepads/`

2×2のグリッドレイアウトで4つの独立したメモを同時に管理。

#### 主な機能
- 4つの独立したメモ欄
- 各メモに文字数カウンター
- 個別のコピー・クリア機能
- 自動保存・復元
- トースト通知
- レスポンシブデザイン（PC: 2×2、タブレット/スマホ: 1列）

#### 使い方
1. 各メモ欄にテキストを入力（自動保存）
2. コピーボタンで個別にクリップボードへコピー
3. クリアボタンで個別に削除

詳細: [README](../fournotepads/README.md)

### 📖 マークダウンビューアー
**ディレクトリ**: `markdownviewer/`

リアルタイムでマークダウンをプレビューできるエディター。

#### 主な機能
- リアルタイムプレビュー（左: 編集、右: プレビュー、それぞれ独立してスクロール可能）
- マークダウン記法フルサポート
  - 見出し、太字、イタリック、取り消し線
  - リスト、リンク、画像
  - コードブロック + シンタックスハイライト（Highlight.js）
  - テーブル、引用、水平線
- ファイル読み込み（「📁 ファイルを開く」ボタン、txt/md、10MBまで）
- ドラッグ&ドロップでのファイル読み込み
- 左右パネル幅のリサイズ（中央の仕切りをドラッグ、20%〜80%）
- 文字数カウント
- 自動保存
- クリップボードにコピー
- .md ファイルでダウンロード
- 全画面プレビュー（ESCで解除）

#### 使い方
1. 左側にマークダウンテキストを入力、またはファイルを開く/ドラッグ&ドロップ
2. 右側でプレビューを確認
3. 中央の仕切りをドラッグしてパネル幅を調整
4. 全画面ボタンでプレビューを拡大表示
5. コピーまたはダウンロードで保存

詳細: [README](../markdownviewer/README.md)

## プレゼンテーションツール

### ⏱️ カウントダウンタイマー
**ディレクトリ**: `countdowntimer/`

プレゼンテーションや会議で使えるカウントダウンタイマー。

#### 主な機能
- 終了時刻指定（時:分形式）
- 分数指定（1〜180分）
- プリセットボタン（5分、10分、15分、20分、30分）
- 残り時間の視覚的表示
- 時間切れ時のアラート
- ローカルストレージによる設定保存

#### 使い方
1. 終了時刻または分数を指定
2. スタートボタンをクリック
3. プレゼンテーション中に残り時間を確認

詳細: [README](../countdowntimer/README.md)

---

### 📊 プログレスバー
**ディレクトリ**: `progressbar/`

プレゼンテーションの残り時間を視覚的に表示するプログレスバー。

#### 主な機能
- **2画面構成**: 設定画面（index.html）+ 表示画面（progress.html）
- プリセットボタン（5分〜120分）
- カスタム時間設定（分・秒単位）
- カラーカスタマイズ（プログレスバー色、背景色）
- フルスクリーン対応（F11キー、ダブルクリック）
- リアルタイム同期（複数ウィンドウ間でLocalStorageで同期）
- 自動保存・復元

#### 使い方
1. **設定画面（index.html）**で時間と色を設定
2. 「プログレスバーウィンドウを開く」をクリック
3. **表示画面（progress.html）**を第2ディスプレイに移動
4. F11キーまたはダブルクリックでフルスクリーン化
5. 設定画面で「開始」をクリック
6. プレゼンテーション中にプログレスバーで進行状況を確認

詳細: [README](../progressbar/README.md) | [クイックスタート](../progressbar/QUICKSTART.md)

## 参加者管理

### 🎰 ランダム抽選ルーレット（発表順ルーレット）
**ディレクトリ**: `roulette/`

参加者の発表順をランダムに決定するルーレットアプリ。

#### 主な機能
- 最大30名対応（6グループ × 5人）
- グループ分け表示による整理
- 完全ランダム抽選（重複なし）
- 段階的な減速演出（約5秒かけて停止）
- 順番固定機能：設定画面（別ウィンドウ `settings.html`）から参加者ごとに固定番号を指定可能。未指定の参加者は残りの番号からランダム抽選
- 結果をタブ区切り形式でコピー（Excel対応）
- 「結果のクリア」（番号だけ削除）と「すべてクリア」（入力内容ごと削除）
- リアルタイム参加者数カウント
- 自動保存・復元
- レスポンシブデザイン（PC: 3列、タブレット: 2列、スマホ: 1列）
- XSS対策・入力検証

#### 使い方
1. 各グループの入力欄に参加者名を入力
2. （任意）「設定」ボタンから順番を固定したい参加者に番号を指定
3. 「スタート」ボタンをクリック
4. ルーレットが回転
5. 「ストップ」ボタンで停止（段階的に減速して約5秒後に完全停止）
6. 割り当てられた番号を確認
7. 「結果をコピー」で Excel に貼り付け可能な形式でコピー

詳細: [README](../roulette/README.md)

### 👥 カウンター付き名簿
**ディレクトリ**: `registerwithcounter/`

参加者ごとの発言回数や行動回数を管理できる名簿アプリ。

#### 主な機能
- 参加者名簿の作成（改行区切り、タブ区切り対応）
- グループ対応（タブ区切りで「グループ名<tab>参加者名」形式）
- 1行目をラベルとして使用可能
- 2つのカスタマイズ可能なカウンター（名前変更可能）
- カウンターの増減（+1/-1ボタン）
- メモ機能（各参加者にメモを追加）
- CSV入出力（データの保存・読み込み）
- 全カウンターのリセット
- 自動保存・復元

#### 使い方
1. 参加者名を入力（改行区切り、またはタブ区切りでグループ名も入力）
2. 「カウンター作成」をクリック
3. カウンター名を必要に応じてカスタマイズ
4. 会議中に各参加者のカウンターを増減
5. メモボタンでコメントを追加
6. 「データダウンロード」でCSV保存

詳細: [README](../registerwithcounter/README.md)

## 会議ツール

### 🎥 Zoom表示名ジェネレーター
**ディレクトリ**: `zoomlink/`

Zoomミーティングのリンクに表示名を埋め込んだカスタムURLを生成。

#### 主な機能
- Zoomミーティングリンクのパース
- カスタム表示名の埋め込み
- 表示名履歴の保存（最大10件）
- 履歴から選択して再利用
- 生成リンクのコピー
- 「すぐに入室」ボタンで直接参加
- ローカルストレージによるデータ保存

#### 使い方
1. ZoomミーティングのURLを貼り付け
2. 表示したい名前を入力（過去に使った名前は履歴から選択可能）
3. 「リンクを生成」をクリック
4. 生成されたリンクをコピー、または「すぐに入室」で参加

詳細: [README](../zoomlink/README.md)

## ユーティリティ

### 🔗 Amazon URLクリーナー
**ディレクトリ**: `amazonurl/`

長いAmazon商品URLからトラッキングパラメータを削除してシンプルなURLに変換。

#### 主な機能
- Amazon URLのパースと変換
- トラッキングパラメータの削除
- アフィリエイトタグの削除
- 複数ドメイン対応（amazon.co.jp, amazon.com, amazon.de など）
- クリップボードにコピー
- エラーメッセージ表示

#### 使い方
1. Amazon商品ページのURLをコピー
2. テキストエリアに貼り付け
3. 「変換する」をクリック
4. シンプルなURLが表示されるのでコピー

#### 変換例
```
変換前: https://www.amazon.co.jp/dp/B08X6PQXX8/ref=sr_1_1?keywords=...
変換後: https://www.amazon.co.jp/dp/B08X6PQXX8
```

詳細: [README](../amazonurl/README.md)

### 📈 株式リンクジェネレーター
**ディレクトリ**: `stockinformation/`

株式コードから複数の投資情報サイトへのリンクを一括生成。

#### 主な機能
- 株式コード（銘柄コード）の入力
- 主要な投資情報サイトへのリンク生成
  - Yahoo!ファイナンス
  - 株探（かぶたん）
  - みんなの株式
  - その他投資情報サイト
- リンクのクリップボードコピー
- 履歴管理（最近調べた銘柄）
- 自動保存・復元

#### 使い方
1. 株式コード（4桁）を入力
2. 「リンク生成」をクリック
3. 各サイトへのリンクが表示される
4. 必要なリンクをクリックして情報を確認

## iPad専用アプリ

### 📱 iPad Clock Apps
**ディレクトリ**: `ipad/`

初代iPad（iOS 5.1.1）から最新デバイスまで対応した時計アプリへのランディングページ。`ipad/index.html` から各時計アプリへリンクする構成です。

#### 含まれるアプリ（10種類）
| アプリ名 | 説明 | パス |
|---------|------|------|
| 12 Hour Clock | シンプルな12時間表示のアナログ風時計 | `12hourclock/` |
| 12 Hour Clock v2 | アイコンで午前/午後を表示する12時間時計 | `12hourclock2/` |
| 24 Hour Clock | シンプルな24時間表示のデジタル時計 | `24hourclock/` |
| API Clock | WorldTimeAPIと同期する正確な24時間時計 | `apiclock/` |
| Chrono Panel 1 | 計器盤風のアナログ＆デジタル時計 | `chrono1/` |
| Chrono Panel 2 | 秒針サブダイヤル付きのクロノグラフ風時計 | `chrono2/` |
| Chrono Panel 3 | 洗練されたUIのクロノグラフ風タイムダッシュボード | `chrono3/` |
| Date Display | 年月日（曜日）を大きく表示するシンプルなアプリ | `date/` |
| 1440 Tiles Clock | 1日の1440分をタイルで可視化する時計 | `tileclock/` |
| 1440 Tiles Clock v2 | スタイルを微調整したタイル時計の別バージョン | `tileclock2/` |

最新の一覧は [ipad/README.md](../ipad/README.md) を参照してください。

#### 技術的特徴
- **初代iPad（iOS 5.1.1）対応**
  - ES5構文のみ使用
  - Float/Inline-blockレイアウト
  - Mobile Safari 5.1互換
- モダンなデザインを100%維持
- グラデーション背景
- ホバーエフェクト
- フルスクリーン対応

#### 重要事項
⚠️ **`ipad/` フォルダは独自の設計方針を採用しています**

プロジェクト全体の設計方針（ES6+、Grid/Flexbox等）は適用されません。開発時は必ず [ipad/DEVELOPMENT_GUIDELINES.md](../ipad/DEVELOPMENT_GUIDELINES.md) を参照してください。

## 🎨 共通デザインシステム

すべてのアプリ（`ipad/` フォルダを除く）は、`css/shared.css` を使用した統一デザインを採用しています。

### ボタンの色ルール
- **コピー** = 緑 (`btn-primary`)
- **クリア** = 赤 (`btn-danger`)
- **ダウンロード** = 青 (`btn-info`)
- **アップロード** = 青 (`btn-info`)

### デザイン要素
- **アクセントカラー**: モダンなグリーン（#10b981）
- **カードスタイル**: シャドウ付き白背景
- **レスポンシブ対応**: モバイル・タブレット・PC
- **トースト通知**: 操作フィードバック
