## 🎯 ドキュメントの役割

### README.md - エントリーポイント

**目的:** プロジェクトの「顔」として、すべての情報への入口を提供

**含まれる内容:**
- プロジェクト概要
- クイックスタート
- 主な特徴
- アプリ一覧（概要）
- 技術スタック
- ドキュメントへのリンク

**読者:** 初めてプロジェクトを見る人、すべてのユーザー

---

### GETTING_STARTED.md - 最初の一歩

**目的:** ユーザーが素早く使い始められるようにする

**含まれる内容:**
- システム要件
- インストール方法（複数の方法）
- 基本的な使い方
- 各アプリの起動方法
- データ保存の説明
- トラブルシューティング

**読者:** 初めて使うユーザー、技術的な知識が少ない人

---

### APPS.md - アプリ詳細ガイド

**目的:** 各アプリの機能と使い方を詳しく説明

**含まれる内容:**
- 全10個の個別Webアプリ + iPad専用コレクション（10種類の時計アプリ）の詳細説明
- 各アプリの主な機能
- 使い方（ステップバイステップ）
- 技術的な特徴
- 共通デザインシステム
- ボタンの色ルール

**読者:** 各アプリの機能を詳しく知りたいユーザー

---

### DEVELOPMENT.md - 開発者のガイド

**目的:** 開発者がカスタマイズや新機能追加ができるようにする

**含まれる内容:**
- 開発環境のセットアップ
- プロジェクト構造の説明
- 新しいアプリの追加方法（ステップバイステップ）
- 共通ユーティリティの使い方
- コーディング規約
- テストとデバッグ方法
- ベストプラクティス

**読者:** アプリを追加したい開発者、カスタマイズしたい人

---

### ARCHITECTURE.md - システム設計

**目的:** システムの深い理解と設計判断の共有

**含まれる内容:**
- システム概要と設計目標
- アーキテクチャ原則
- レイヤー構造
- 主要コンポーネント
- データフロー
- デザインパターン
- セキュリティ設計
- パフォーマンス最適化

**読者:** 上級開発者、アーキテクチャに興味がある人

---

### REFACTORING_GUIDE.md - リファクタリングガイド

**目的:** 既存アプリや外部アプリをプロジェクト標準に準拠させる

**含まれる内容:**
- リファクタリングの基本方針
- ステップバイステップガイド
- クラスベース設計への移行
- 共通スタイルの適用
- アプリ固有のデザイン制約への対処
- チェックリスト
- 参考事例

**読者:** 既存アプリをリファクタリングする開発者

---

### MIGRATION.md - 移行ガイド

**目的:** 旧バージョンから新バージョンへのスムーズな移行

**含まれる内容:**
- 主な変更点（Before/After）
- 移行前の準備
- 段階的移行手順
- Breaking Changes
- データの移行方法
- トラブルシューティング

**読者:** v1.xから移行する既存ユーザー、開発者

---

### FAQ.md - よくある質問

**目的:** 一般的な質問への素早い回答

**含まれる内容:**
- 一般的な質問
- インストールと起動
- データと保存
- トラブルシューティング
- カスタマイズと開発
- セキュリティとプライバシー

**読者:** すべてのユーザー、特に問題に直面している人

---

### CONTRIBUTING.md - 貢献ガイド

**目的:** オープンソースコントリビューションの促進

**含まれる内容:**
- 行動規範
- 貢献の種類（バグ報告、機能リクエスト、コード）
- 開発の流れ
- コーディング規約
- コミットメッセージ規約
- プルリクエストプロセス

**読者:** プロジェクトに貢献したい開発者

---

### CHANGELOG.md - 変更履歴

**目的:** バージョンごとの変更を追跡

**含まれる内容:**
- 各バージョンの変更内容
- Added / Changed / Fixed / Deprecated
- Breaking Changes
- 今後の予定

**読者:** すべてのユーザー、特にアップデート内容を確認したい人

---

## 🗺️ 読者別ナビゲーション

### 👤 初めてのユーザー

```
1. README.md - プロジェクト概要を理解
2. GETTING_STARTED.md - インストールして使い始める
3. APPS.md - 各アプリの詳細な機能を確認
4. FAQ.md - 困ったときに参照
```

### 👨‍💻 開発者（カスタマイズしたい）

```
1. README.md - プロジェクト概要
2. GETTING_STARTED.md - 基本的な使い方を理解
3. DEVELOPMENT.md - 開発環境をセットアップ
4. REFACTORING_GUIDE.md - 既存アプリのリファクタリング手順（必要に応じて）
5. ARCHITECTURE.md - 設計を理解（任意）
6. CONTRIBUTING.md - 貢献方法を確認（任意）
```

### 🏗️ 上級開発者（深く理解したい）

```
1. README.md - プロジェクト概要
2. ARCHITECTURE.md - システム設計を理解
3. DEVELOPMENT.md - 実装の詳細
4. CHANGELOG.md - 変更履歴を確認
5. CONTRIBUTING.md - 貢献方法
```

### 🔄 既存ユーザー（v1.xからの移行）

```
1. CHANGELOG.md - 変更内容を確認
2. MIGRATION.md - 移行手順に従う
3. FAQ.md - 問題が発生したら参照
4. DEVELOPMENT.md - 新機能を理解（任意）
```

## 📝 ドキュメントの更新

### 更新が必要なタイミング

| 変更内容 | 更新すべきドキュメント |
|---------|---------------------|
| 新機能追加 | README.md, CHANGELOG.md, DEVELOPMENT.md, APPS.md |
| 新アプリ追加 | README.md, CHANGELOG.md, APPS.md, js/config.js |
| バグ修正 | CHANGELOG.md, FAQ.md（必要に応じて） |
| API変更 | DEVELOPMENT.md, ARCHITECTURE.md, MIGRATION.md |
| 設計変更 | ARCHITECTURE.md, DEVELOPMENT.md, REFACTORING_GUIDE.md |
| Breaking Changes | CHANGELOG.md, MIGRATION.md |
| よくある質問 | FAQ.md |
| ドキュメント追加 | DOCS_STRUCTURE.md |

### ドキュメント品質チェックリスト

```markdown
- [ ] 明確で簡潔な文章
- [ ] コード例が正確で動作する
- [ ] スクリーンショットが最新
- [ ] リンクが切れていない
- [ ] 目次が更新されている
- [ ] タイポがない
- [ ] 読者の視点で書かれている
```

## 🎨 ドキュメントスタイルガイド

### 見出しレベル

```markdown
# H1 - ドキュメントタイトル（1つのみ）
## H2 - メインセクション
### H3 - サブセクション
#### H4 - 詳細項目
```

### 絵文字の使用

適度に使用して、視覚的に区別しやすくする:

- 📋 目次、リスト
- 🎯 目的、目標
- ✨ 新機能、ハイライト
- 🔄 変更、更新
- 🐛 バグ、問題
- 🔒 セキュリティ
- ⚡ パフォーマンス
- 📚 学習、リソース
- 💡 ヒント、提案
- ⚠️ 警告、注意
- ✅ 完了、成功
- ❌ 禁止、失敗
