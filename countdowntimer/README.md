# カウントダウンタイマー

シンプルで見やすいカウントダウンタイマーWebアプリケーション。終了時刻または経過分数を指定してカウントダウンを表示します。

> このアプリは「Webアプリ集」プロジェクトの一部として統合されています。[プロジェクト全体のドキュメント](../README.md)もご覧ください。

## 📋 プロジェクト概要

このアプリケーションは、プレゼンテーションや作業時間の管理、イベントまでの時間表示など、様々なシーンで使えるカウントダウンタイマーです。大きく見やすい表示で、残り時間を一目で確認できます。

## ✨ 実装済み機能

### 🎯 設定画面
- **2つのタイマーモード選択**
  - 終了時刻指定モード：特定の時刻（例：15:30）に0になるようカウントダウン
  - 分数指定モード：指定した分数と秒数（例：45分30秒）経過後に0になるようカウントダウン
- **3つの色モード**
  - ライトモード：白背景（デフォルト）
  - ダークモード：黒背景
  - カスタムモード：背景色と文字色を自由に設定
- **直感的なUI**：ラジオボタンで簡単にモード切り替え
- **入力バリデーション**：未入力や不正な値をチェック

### ⏱️ カウントダウン実行画面
- **3つの時刻表示**
  1. 現在時刻（リアルタイム更新）
  2. カウントダウン（最も大きく表示）
  3. 終了予定時刻

- **カウントダウン表示の自動切替**
  - **残り2分以上**: 「残り **XX** 分」形式（数字部分を強調）
  - **残り2分未満**: 「残り **X分XX秒** 」形式（時間全体を強調）
  
- **視認性の高いデザイン**
  - カウントダウン：最大・太字（8rem/6rem）
  - 現在時刻・終了時刻：控えめなサイズ（2rem）
  - 「残り」「分」などのラベル：薄く小さめ（2.5rem）

- **設定ボタン**：右上に配置、薄く表示して邪魔にならないデザイン
- **一時停止/再開機能**：タイマーを一時停止して再開できる
- **フラッシュ通知**：残り30秒、20秒、10秒、5秒、2秒、1秒で画面がフラッシュ

### 🎨 デザイン特徴
- **3つの色モード**：ライト、ダーク、カスタムから選択可能
- **レスポンシブ対応**：スマートフォンからPCまで対応
- **共通デザインシステム**：shared.cssで統一されたスタイル
- **視覚的フィードバック**：時間経過に応じたフラッシュ効果

## 🚀 使い方

### 基本的な使用方法

1. **アプリを開く**
   - Webアプリ集のトップページから「カウントダウンタイマー」をクリック
   - または直接 `countdowntimer/index.html` をブラウザで開く

2. **タイマーモードを選択**
   - **終了時刻指定**: 時刻入力フィールドで終了時刻を設定（例：15:30）
   - **分数指定**: 分数と秒数を入力（例：45分30秒）

3. **色モードを選択**（オプション）
   - ライト / ダーク / カスタムから選択
   - カスタムモードでは背景色と文字色を自由に設定

4. **「開始」ボタンをクリック**
   - シンプルな別ウインドウ（ポップアップ）が開き、カウントダウン表示が始まる
   - ポップアップがブロックされた場合は、ブラウザの設定で許可する

5. **タイマーの操作**
   - 「一時停止」ボタンでタイマーを一時停止/再開
   - 右上の「閉じる」ボタンで表示ウインドウを閉じる
   - 設定を変更して再度「開始」を押すと、既存の表示ウインドウが新しい設定で更新される（多重に開かない）

### 使用例

**プレゼンテーションの時間管理**
- 分数指定で「30分」に設定
- プレゼン開始と同時にタイマーを開始
- 大きな画面で残り時間を確認

**会議の終了時刻までのカウントダウン**
- 終了時刻指定で「17:00」に設定
- 会議室のモニターに表示
- 参加者全員が終了時刻を意識できる

## 🛠️ 技術スタック

### フロントエンド
- **HTML5** - セマンティックマークアップ
- **CSS3** - CSS Variables、Flexbox、アニメーション
- **Vanilla JavaScript** - ES6+クラス構文

### アーキテクチャ
- **設定画面と表示ウインドウの分離**: `CountdownTimer`（設定画面）が`window.open()`で`timer-display.html`を別ウインドウとして開き、`CountdownDisplay`（表示ウインドウ）がカウントダウンを表示する
- **ウインドウ間のデータ受け渡し**: 終了時刻（epoch ms）・色モード・カスタムカラーをURLクエリパラメータとして渡す（`AppUtils.getQueryParams()`で受信）
- **同名ウインドウの再利用**: `window.open()`に固定のウインドウ名を指定し、再度「開始」を押しても表示ウインドウが多重に開かないようにする
- **共通スタイルシステム**: `shared.css`で統一されたデザイン
- **共通ユーティリティ**: `AppUtils`で再利用可能な機能
  - `formatDate()` - 日付と時刻のフォーマット
  - `getQueryParams()` - URLクエリパラメータの取得
- **状態管理**: インスタンス変数で状態を管理
- **イベント駆動**: クリーンなイベントリスナー設計

### デザインシステムの活用
```css
/* CSS変数で統一されたテーマカラー */
var(--accent-color)      /* アクセントカラー */
var(--text-primary)      /* メインテキスト色 */
var(--border-color)      /* ボーダー色 */
var(--bg-color)          /* 背景色 */
```

### 主要機能の実装

**カウントダウン計算**
- `setInterval()`で1秒ごとに更新
- ミリ秒単位で正確な時間計算
- 終了時刻はタイムスタンプで管理

**設定画面から表示ウインドウを開く**
- `window.open()`で`timer-display.html`を別ウインドウとして起動
- 終了時刻・色設定はURLクエリパラメータで渡す
- CSSクラス（`.active`）による表示制御とアニメーション

**時刻フォーマット**
- AppUtils.formatDateを使用
- 24時間形式（HH:mm）
- 統一されたフォーマット処理

## 🎯 動作要件

- JavaScript有効化必須

## 📂 ファイル詳細

### index.html
- 共通スタイル（`shared.css`）を先に読み込み
- アプリ固有スタイル（`style.css`）を後で読み込み
- 共通ユーティリティ（`utils.js`）を先に読み込み
- 設定画面ロジック（`timer.js`）を後で読み込み
- 設定画面のみで構成（「開始」で`timer-display.html`を別ウインドウで開く）

### timer-display.html
- `index.html`と同じ`shared.css`／`style.css`を読み込み
- 共通ユーティリティ（`utils.js`）を先に読み込み
- 表示ロジック（`display.js`）を後で読み込み
- カウントダウン表示のみで構成（設定UIは含まない）

### css/style.css
- 共通スタイルを再定義せず、アプリ固有のスタイルのみ記述
- CSS変数を活用して統一感を保持
- 設定画面・表示ウインドウ双方のスタイル（画面切り替えとアニメーションを含む）を定義
- ダークモードとカスタムカラーのスタイル

### js/timer.js
- `CountdownTimer`クラスで設定画面の機能を実装
- 入力バリデーションと、表示ウインドウ用URLの組み立て・`window.open()`
- `AppUtils`の共通関数を活用

### js/display.js
- `CountdownDisplay`クラスで表示ウインドウの機能を実装
- URLクエリパラメータ（`AppUtils.getQueryParams()`）から終了時刻・色設定を取得
- フラッシュ効果と色モードの適用、一時停止/再開
