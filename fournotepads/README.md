# 4分割メモ帳

ブラウザ上で動作する2×2のグリッドレイアウトのメモ帳アプリケーションです。

## 🎯 プロジェクト概要

4つの独立したメモ欄を持つシンプルで使いやすいメモアプリです。それぞれのメモ欄は独立して動作し、個別に管理できます。

## ✨ 実装済み機能

### 基本機能
- ✅ **2×2のグリッドレイアウト**: 4つのメモ欄を均等に配置
- ✅ **文字数カウンター**: リアルタイムで各メモの文字数を表示
- ✅ **コピーボタン**: クリックでクリップボードにテキストをコピー
- ✅ **クリアボタン**: 確認ダイアログ付きでテキストを削除
- ✅ **トースト通知**: 操作完了時に視覚的なフィードバック

### 追加機能
- ✅ **自動保存**: LocalStorageを使用してテキストを自動保存
- ✅ **自動復元**: ページ再読み込み時にテキストを自動復元
- ✅ **レスポンシブデザイン**: スマートフォン・タブレットにも対応
- ✅ **モダンなUI**: グラデーション背景とホバーエフェクト

## 🚀 機能の使い方

### メモの入力
各メモ欄にテキストを入力すると、自動的にローカルストレージに保存されます。

### 文字数カウント
入力中にリアルタイムで文字数が表示されます。

### コピー機能
1. 📋 コピーボタンをクリック
2. テキストがクリップボードにコピーされます
3. 「コピーしました！」というメッセージが表示されます

### クリア機能
1. 🗑️ クリアボタンをクリック
2. 確認ダイアログが表示されます
3. 「OK」をクリックするとテキストが削除されます

## 🎨 デザイン特徴

- **共通デザインシステム**: shared.cssで統一されたスタイル
- **カード型デザイン**: 各メモ欄を白いカードで表現
- **ホバーエフェクト**: マウスオーバー時の浮き上がり効果
- **レスポンシブ**: モバイル表示時は1カラムに自動変更
- **CSS変数**: 統一されたカラーテーマ

## 💾 データ保存

- **保存方法**: LocalStorage使用
- **保存タイミング**: テキスト入力時に自動保存
- **復元タイミング**: ページ読み込み時に自動復元

## 🛠️ 技術スタック

### フロントエンド
- **HTML5** - セマンティックマークアップ
- **CSS3** - Grid Layout、Flexbox、CSS Variables
- **Vanilla JavaScript** - ES6+クラス構文

### アーキテクチャ
- **クラスベース設計**: `FourNotepads`クラスで全機能をカプセル化
- **共通スタイルシステム**: `shared.css`で統一されたデザイン
- **共通ユーティリティ**: `AppUtils`で再利用可能な機能

  - `copyToClipboard()` - クリップボード操作
- **LocalStorage API** - データ永続化
- **Clipboard API** - クリップボード操作

## 📂 ファイル詳細

### index.html
- 共通スタイル（`shared.css`）を先に読み込み
- アプリ固有スタイル（`style.css`）を後で読み込み
- 共通ユーティリティ（`utils.js`）を先に読み込み
- メイン機能（`notepads.js`）を後で読み込み
- 2×2グリッドレイアウトで４つのメモ欄を配置

### css/style.css
- 共通スタイルを再定義せず、アプリ固有のスタイルのみ記述
- CSS変数を活用して統一感を保持
- グリッドレイアウトとレスポンシブデザイン

### js/notepads.js
- `FourNotepads`クラスで全機能を実装
- `AppUtils`の共通関数を活用
- イベント駆動型の設計
- 4つのメモを独立管理
