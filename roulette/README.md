# 🎰 ランダム抽選ルーレット

参加者の名前を入力して、ランダムに番号を抽選するWebアプリケーションです。ルーレットのように数字が回転し、徐々に減速して停止する演出が特徴です。

## 📋 プロジェクト概要

このアプリケーションは、イベントやゲーム、プレゼン順決めなどで使用できるランダム抽選ツールです。表形式の入力欄に名前を入力するだけで、各参加者に1から人数分の番号を重複なく自動的に割り当てます。

## ✨ 主な機能

### 実装済み機能

1. **表形式の名前入力機能**
   - 5人×1グループの入力フィールドが6グループ（2行×3列）
   - 合計30人まで入力可能
   - リアルタイムで参加者数をカウント表示
   - 入力済みのフィールドは背景色が変化（視覚的フィードバック）
   - 大きく太い文字（2.8rem、bold）で遠くからでも見やすい
   - LocalStorageによる自動保存機能（入力内容の保持）

2. **ルーレット抽選機能**
   - 「スタート」ボタンで抽選開始
   - 各参加者の横で1～人数分の番号が高速でランダム表示
   - 数字の重複なし（全員が異なる番号を取得）
   - 大きく太い番号表示（2rem、bold）で視認性抜群
   - フラッシュ演出で抽選完了を視覚的にアピール

3. **段階的減速停止機能**
   - 「ストップ」ボタンで停止開始
   - 5段階の減速フェーズで約5秒かけて徐々に停止
   - フェーズ1: 通常減速（2.5秒）50ms→400ms
   - フェーズ2: 500ms間隔で5回
   - フェーズ3: 800ms間隔で2回
   - フェーズ4-5: 1秒間隔で2回
   - 最終的にすべての参加者に固有の番号が確定
   - 1番と最終番号は濃いオレンジ、その他は淡いオレンジで色分け

4. **結果コピー機能**
   - 「結果をコピー」ボタンでタブ区切り形式でクリップボードにコピー
   - コピー形式: `名前[TAB]番号`（Excelなどに貼り付け可能）
   - コピー成功時に視覚的なフィードバック
   - 抽選結果がある場合のみボタンが有効化

5. **クリア機能**
   - 「結果のクリア」ボタン: 参加者名はそのままで結果（番号）だけをクリア
   - 「すべてクリア」ボタン: 入力内容と結果を一括削除
   - ルーレット中はクリア操作を防止

6. **データ永続化機能**
   - LocalStorageに参加者名を自動保存
   - ページリロード後も入力内容を自動復元
   - デバウンス処理（500ms）で保存頻度を最適化

7. **順番固定機能（設定画面）**
   - 「設定」ボタンから別ウィンドウ（`settings.html`）を開く
   - 参加者ごとに固定の抽選番号（1〜現在の参加者数）を指定可能
   - 番号を指定された参加者は抽選結果が必ずその番号になる
   - 未指定の参加者は残りの番号からランダムに割り当てられる（重複なし）
   - 番号の重複・範囲外の入力は保存時に防止（保存ボタンが無効化される）
   - 参加者数が変化した後の古い設定・不正な値は抽選時に自動的に無視され、安全側でランダム抽選に降格する
   - メイン画面で参加者リストが変わると、開いたままの設定画面もリアルタイムに追従する

8. **レスポンシブデザイン**
   - PC: 3列表示（6グループすべて表示）
   - タブレット: 2列表示に自動調整
   - スマートフォン: 1列表示に自動調整
   - モダンなグラデーションUIデザイン

## 🚀 使い方

1. **参加者の名前を入力**
   - 表形式の入力フィールドに名前を入力
   - 6グループ（各グループ5人）の合計30人まで入力可能
   - グループ1～6まで整理された構造
   - 入力するとフィールドの背景色が変化

2. **（任意）順番を固定する**
   - 「設定」ボタンをクリックすると順番設定ウィンドウが開く
   - 固定したい参加者の欄に番号（1〜現在の参加者数）を入力して「保存」
   - 未入力の参加者はランダムに抽選される

3. **抽選を開始**
   - 「スタート」ボタンをクリック
   - 各名前の横で番号が高速でランダム表示されます

4. **抽選を停止**
   - 「ストップ」ボタンをクリック
   - 徐々に減速して約5秒後に完全停止
   - 1番と最終番号は濃いオレンジで強調表示

5. **結果をコピー**
   - 「結果をコピー」ボタンをクリック
   - タブ区切り形式でクリップボードにコピー
   - Excelやスプレッドシートに貼り付け可能

6. **再抽選・クリア**
   - 同じメンバーで再抽選: 「結果のクリア」→「スタート」
   - すべてリセット: 「すべてクリア」ボタンをクリック
   - 入力内容は自動保存されるため、ページを閉じても復元可能

## 🎨 デザインの特徴

- **大きな文字サイズ**: 
  - 参加者名: 2.8rem（bold）- 遠くからでも見やすい
  - 順番番号: 2rem（bold）- 視認性抜群
- **表形式レイアウト**: 6グループ（2行×3列）で整理された入力欄
- **グループヘッダー**: 各グループに「グループ1」～「グループ6」のラベル
- **視覚的フィードバック**: 
  - 入力済みフィールドは背景色が薄緑色に変化
  - 抽選中は番号が緑色でスピン
  - 確定後は1番・最終番号が濃いオレンジ、その他が淡いオレンジ
- **アニメーション効果**: 
  - 数字回転時のパルスアニメーション
  - 停止時のバウンスイン効果
  - 抽選完了時のフラッシュ演出
- **共有デザインシステム**: 
  - 共通CSSによる統一されたUI/UX
  - トースト通知による操作フィードバック

## 📱 レスポンシブ対応

- **デスクトップ（1024px以上）**: 3列表示（すべてのグループが横並び）
- **タブレット（768px～1024px）**: 2列表示に自動調整
- **スマートフォン（768px以下）**: 1列表示に自動調整

## 🔧 技術仕様

### 使用技術
- **HTML5**: セマンティックなマークアップ
- **CSS3**: Flexbox、Grid、アニメーション、CSS Variables
- **JavaScript (ES6+)**: モダンなJavaScript構文
  - クラスベースのアーキテクチャ（RouletteApp）
  - Fisher-Yatesシャッフルアルゴリズム（AppUtils.shuffle）
  - Clipboard API（AppUtils.copyToClipboard）
  - LocalStorage API（AppUtils.saveToStorage/loadFromStorage）
  - デバウンス処理（AppUtils.debounce）
  - DOM操作とイベントハンドリング

### 主要アルゴリズム
1. **Fisher-Yatesシャッフル**: 配列をランダムに並び替え（共通ユーティリティ）
2. **5段階減速アルゴリズム**: 時間経過に応じてスピードを段階的に低下
   - フェーズ1: 50ms→400ms（2.5秒）
   - フェーズ2: 500ms × 5回
   - フェーズ3: 800ms × 2回
   - フェーズ4-5: 1000ms × 2回
3. **重複防止ロジック**: 各参加者に一意の番号を保証
4. **XSS対策**: すべての入力値をエスケープ処理（AppUtils.escapeHtml）

### セキュリティ機能
- XSS攻撃対策: HTML特殊文字のエスケープ処理
- 入力値検証: 50文字以内の制限
- ルーレット中の操作制限: 状態管理による安全な操作

## 📊 データモデル

このアプリケーションはクライアントサイドのみで動作し、サーバーやデータベースは使用していません。

### データ保存
- **LocalStorage**: 参加者名を自動保存
  - キー: `roulette_names`
  - 値: `{names: string[], timestamp: number}`
  - デバウンス処理により500ms後に保存
- **LocalStorage**: 順番固定設定を保存
  - キー: `roulette_fixed_numbers`
  - 値: `{assignments: (number|null)[], names: string[], timestamp: number}`
  - `assignments[i]` は `roulette_names.names[i]`（詰めた参加者順）に対応する固定番号。`null` はランダム割当。
  - `names` は保存時点の参加者名スナップショット（設定画面での「古い設定」警告に使用）
  - 参加者数の変化・範囲外の値・重複した値は抽選時に自動的に無視され、安全側（ランダム抽選）にフォールバックする

### 状態管理
アプリケーションの状態は`RouletteApp`クラスの`state`オブジェクトで管理：
```javascript
{
  names: [],              // 参加者情報の配列
  isSpinning: false,      // ルーレット実行中フラグ
  spinInterval: null,     // タイマーID
  spinSpeed: 50,          // 現在の回転速度（ms）
  slowDownStartTime: 0,   // 減速開始時刻
  assignedNumbers: [],    // 割り当て済み番号
  spinCount: 0           // 減速フェーズのカウント
}
```
