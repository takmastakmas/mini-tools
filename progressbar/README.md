# 📊 プレゼンテーション用プログレスバーWebアプリ

PowerPointやKeynoteなどのプレゼンテーション中に、サブディスプレイ上で残り時間を視覚的に表示するプログレスバーを提供し、発表者と聴衆が時間管理を容易にするWebアプリケーションです。

![Version](https://img.shields.io/badge/version-1.0.0-blue.svg)

---

## 🎯 主要機能

### ✅ 完成している機能

1. **タイマー設定機能**
   - プリセット時間選択（5分、10分、15分、20分、30分、45分、60分）
   - カスタム時間入力（分・秒単位で自由に設定可能）

2. **プログレスバー専用ポップアップウィンドウ**
   - 画面下部に固定表示
   - サブディスプレイでの使用に最適化
   - フルスクリーン対応（F11キーまたはダブルクリック）

3. **リアルタイム時間同期**
   - BroadcastChannel APIによる高速同期
   - LocalStorageフォールバックで互換性確保
   - メイン画面とプログレスバーウィンドウが完全同期

4. **視覚的な警告表示**
   - 残り時間30%以上：緑色（通常）
   - 残り時間10-30%：オレンジ色（注意）
   - 残り時間10%以下：赤色（危険）
   - 残り時間10%以下で点滅エフェクト（オプション）

5. **カスタマイズ可能な設定**
   - プログレスバーの高さ調整（10px～300px）
   - 3段階の色をカスタマイズ可能
   - 残り時間表示のON/OFF
   - 点滅エフェクトのON/OFF（残り10%以下）
   - 設定のクリア機能（デフォルト値に戻す）
   - リアルタイム設定反映（進行中でも即座に反映）

6. **コントロール機能**
   - 開始/一時停止/リセットボタン
   - リアルタイム進行状況表示
   - 状態の自動保存と復元
   - 設定のクリア（記録を完全に削除）

## 🚀 使用方法

### 基本的な使い方

1. **index.html を開く**
   - ブラウザで `index.html` を開いてメインコントロール画面を表示

2. **時間を設定**
   - プリセットボタンをクリック、またはカスタム時間を入力

3. **プログレスバーウィンドウを開く**
   - 「プログレスバーウィンドウを開く」ボタンをクリック
   - 新しいウィンドウが開き、画面下部にプログレスバーが表示されます
   - サブディスプレイがある場合は、そちらに移動することをおすすめします

4. **タイマーを開始**
   - メインコントロール画面で「開始」ボタンをクリック
   - プログレスバーがリアルタイムで進行します

5. **プレゼンテーションを開始**
   - プログレスバーウィンドウをサブディスプレイに配置
   - PowerPointなどを全画面表示してプレゼンテーションを実施
   - プログレスバーで時間管理を行います

### 💡 URLバーやタイトルバーを非表示にする方法

プログレスバーをよりシンプルに表示したい場合：

1. プログレスバーウィンドウで **F11キー** を押す
2. または、プログレスバーウィンドウを**ダブルクリック**
3. フルスクリーンモードになり、URLバーとタイトルバーが非表示になります
4. 元に戻すには、再度 **F11キー** または **Escキー** を押します

### プログレスバーウィンドウの操作

- **F11キー**: フルスクリーン切り替え（URLバー/タイトルバーを非表示）
- **ダブルクリック**: フルスクリーン切り替え
- **Escキー**: フルスクリーン解除 / ウィンドウを閉じる

### 設定のカスタマイズ

1. メインコントロール画面の「設定」セクションで各種設定を調整
2. 「設定を保存」ボタンをクリックして保存
3. 設定は次回起動時にも引き継がれます

## 🔧 技術仕様

### 技術スタック

- **HTML5**: セマンティックな構造
- **CSS3**: モダンなスタイリングとアニメーション
- **Vanilla JavaScript**: フレームワーク不要の軽量実装

### ブラウザ対応

- ✅ Google Chrome（推奨）
- ✅ Microsoft Edge
- ✅ Firefox
- ✅ Safari

### データ管理

- **LocalStorage**: 設定とタイマー状態の永続化
- **BroadcastChannel API**: ウィンドウ間のリアルタイム通信
- **Storage Event**: タブ間の状態同期

### 主要なAPIと機能

1. **BroadcastChannel API**
   - メイン画面とプログレスバーウィンドウ間の高速通信
   - フォールバックとしてLocalStorageポーリングも実装

2. **Web Storage API (LocalStorage)**
   - 設定の永続化
   - タイマー状態の保存と復元
   - ウィンドウ間のデータ共有

3. **Web Audio API**
   - アラーム音の生成（開発中）

4. **Fullscreen API**
   - プログレスバーのフルスクリーン表示

## 🛠️ トラブルシューティング

### プログレスバーウィンドウが同期しない

- ブラウザがBroadcastChannel APIをサポートしているか確認してください
- LocalStorageが有効になっているか確認してください
- ブラウザのコンソールでエラーメッセージを確認してください

### プログレスバーウィンドウが開かない

- ポップアップブロッカーが有効になっていないか確認してください
- ブラウザの設定でポップアップを許可してください

### 設定が保存されない

- ブラウザのプライベートモード/シークレットモードでは、LocalStorageが制限される場合があります
- 通常モードでの使用をお試しください

### タイマーが正確に動作しない

- ブラウザのタブがバックグラウンドになると、タイマーの精度が低下する場合があります
- メインコントロール画面のタブをアクティブに保つことをお勧めします
