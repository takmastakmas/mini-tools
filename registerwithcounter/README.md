# 参加者カウンター管理アプリ

シンプルで使いやすい参加者カウンター管理Webアプリケーションです。参加者名簿を入力するだけで、各参加者にカウンターが自動生成され、クリックで簡単にカウントアップできます。

## 📋 プロジェクト概要

このアプリケーションは、イベントや会議、セミナーなどで参加者ごとの発言回数や行動回数をカウントするために設計されました。直感的なUIと簡単な操作で、リアルタイムでカウント管理が可能です。

**🎨 統一されたデザイン**: 他のWebアプリと共通のスタイルシート（shared.css）を使用し、モダンで統一感のあるデザインを実現しています。

## ✨ 完成済み機能

### 🎯 コア機能
- ✅ **参加者名簿入力**: テキストエリアに改行区切りで参加者名を入力
- ✅ **タブ区切りデータ対応**: グループ情報付きデータ（タブ区切り）に対応
- ✅ **行ラベル機能**: 1行目を行ラベルとして使用するオプション
- ✅ **グループ表示**: グループ情報がある場合、自動的にグループ列を表示
- ✅ **インライン編集**: テーブル上で直接グループ名・参加者名を編集可能
- ✅ **テーブル形式表示**: 名前とカウンターが縦に並ぶ見やすい表形式
- ✅ **2つのカウンター**: 各参加者に2つのカウンター（カウンターA・カウンターB）を自動生成
- ✅ **カウンター名変更**: カウンターA・Bの名前をカスタマイズ可能
- ✅ **色分けUI**: カウンターAは青系、カウンターBは緑系で視覚的に区別
- ✅ **増減ボタン**: 各カウンターに「+1」ボタンと「-1」ボタンを配置
- ✅ **個別リセット**: 各カウンター（A・B）を個別にリセット可能（確認なし）
- ✅ **全体リセット**: 全参加者の全カウントを一括でリセット
- ✅ **カウンター削除**: 全てのカウンターを削除して初期状態に戻す
- ✅ **参加者削除**: 不要な参加者を個別に削除可能
- ✅ **視覚的グループ化**: カウンターごとにボタンをグループ化し、操作性を向上
- ✅ **ソート機能**: 各列ヘッダーをクリックして昇順・降順でソート可能
- ✅ **メモ・コメント機能**: 各参加者にメモを追加可能
- ✅ **CSV入出力**: データをCSVファイルでダウンロード・アップロード可能（メモも含む）
- ✅ **自動保存**: データ変更時に自動的にローカルストレージに保存

### 📊 統計情報
- ✅ **参加者数表示**: 現在登録されている参加者の総数を表示
- ✅ **合計カウント表示**: 全参加者のカウント合計をリアルタイム表示

### 💾 データ永続化
- ✅ **ローカルストレージ保存**: ブラウザを閉じてもデータが保持される
- ✅ **自動復元**: ページを再読み込みしても前回のデータが自動復元

### 🎨 UI/UX
- ✅ **レスポンシブデザイン**: スマートフォン、タブレット、PCに対応
- ✅ **アニメーション効果**: カウントアップ時の視覚的フィードバック
- ✅ **ホバーエフェクト**: カードやボタンの直感的な反応

## 🚀 使い方

### 基本的な使い方

1. **参加者名簿の入力**
   
   **方法1: シンプルな名前リスト**
   ```
   名前
   鈴木
   山田
   伊藤
   ```
   
   **方法2: グループ付きデータ（タブ区切り）**
   ```
   グループ	名前
   A	鈴木
   A	山田
   A	伊藤
   B	田中
   B	後藤
   B	高橋
   C	山下
   C	小林
   ```
   ※ExcelやGoogleスプレッドシートからコピー＆ペーストできます
   
   - 必要に応じて「1行目を行ラベルとして使用する」にチェックを入れる
   - チェックを入れた場合、1行目がテーブルのヘッダーとして表示されます

2. **カウンター作成**
   - 「カウンター作成」ボタンをクリック
   - 自動的にテーブル形式でカウンターが生成されます
   - デフォルトで「カウンターA」「カウンターB」の2つのカウンターが各参加者に割り当てられます

**または**

2. **データアップロード**
   - 「データアップロード」ボタンをクリック
   - 保存済みのCSVファイルを選択して一括読み込み
   - グループ情報やカウンター名も自動的に復元されます

3. **カウンター名のカスタマイズ（オプション）**
   - カウンター管理エリアの「カウンター名」欄で名前を変更
   - 例: 「カウンターA」→「発言回数」、「カウンターB」→「質問回数」
   - 「更新」ボタンをクリックして反映

4. **カウントアップ・ダウン**
   - カウンターAは青色のボタン、カウンターBは緑色のボタンで色分け
   - 各カウンターボタン（数字が表示されたボタン）をクリックで+1
   - 「-」ボタンをクリックで-1（0以下にはなりません）
   - カウンターA・Bを独立して操作可能

5. **データの編集**
   - グループ名や参加者名をテーブル上で直接クリックして編集可能
   - 変更は自動的に保存されます

6. **ソート機能**
   - 各列のヘッダー（グループ、名前、カウンターA、カウンターB）をクリックしてソート
   - 1回クリック: 昇順ソート
   - 2回クリック: 降順ソート
   - ソートアイコンで現在の状態を表示
   - 例: カウンターAでソートして、カウント数の多い順に並べ替え

7. **メモ・コメント機能**
   - 📝 各行のメモボタン（付箋アイコン）をクリック
   - モーダルダイアログでメモを入力・編集
   - メモがある場合はボタンが黄色に変化し、メモアイコンが塗りつぶされます
   - ホバーでメモの内容をツールチップでプレビュー表示
   - CSV出力にもメモ列が含まれます
   - CSVからメモ付きでインポートも可能

8. **リセット・削除**
   - 🔄 個別カウンターリセット: 各カウンターのリセットボタンで個別にリセット（確認なし）
   - 🔄 全てリセット: 上部の「全てリセット」ボタンで全カウント数を一括リセット（参加者は残る）
   - 🗑️ カウンター削除: 上部の「カウンター削除」ボタンで全てのカウンターを削除し初期状態に戻す
   - 🗑️ 個別削除: 各行の削除ボタンで参加者を個別に削除

8. **データの入出力**
   - 📥 **データダウンロード**: 現在のデータをCSVファイルとしてダウンロード（カウンター管理エリア）
   - 📤 **データアップロード**: CSVファイルからデータを読み込み（参加者名簿入力エリア）
   - ExcelやGoogleスプレッドシートとの互換性あり
   - ファイル名には日時が自動付与（例: `counter_data_20231231_1430.csv`）

### 便利な機能

- **重複チェック**: 同じ名前の参加者は自動的にスキップされます
- **データ永続化**: ブラウザを閉じても次回起動時にデータが復元されます
- **統計情報**: 参加者数がリアルタイムで更新されます
- **CSV互換**: ExcelやGoogleスプレッドシートで作成したデータをそのまま使用可能

## 🔧 カスタマイズ方法

### カラースキームの変更

`css/shared.css`のCSS変数を変更することで、アプリ全体のカラースキームをカスタマイズできます：

```css
:root {
    --accent-color: #10b981;  /* メインカラー */
    --accent-hover: #059669;  /* ホバー時のカラー */
    --bg-color: #f8fafc;      /* 背景色 */
    --surface-color: #ffffff; /* カード背景色 */
    --text-primary: #1f2937;  /* メインテキスト色 */
}
```

### カウンターボタンの色変更

`index.html`のstyleセクションでカウンターボタンの色をカスタマイズできます：

```css
/* カウンターAを緑系に変更 */
.counter-btn-a {
    background-color: #10b981;
}

/* カウンターBを紫系に変更 */
.counter-btn-b {
    background-color: #8b5cf6;
}
```
