# ブラウザメモ帳

シンプルで使いやすいブラウザベースのメモ帳アプリケーションです。

> このアプリは「Webアプリ集」プロジェクトの一部として統合されています。[プロジェクト全体のドキュメント](../README.md)もご覧ください。

## 🎯 完成した機能

- ✅ タイトル入力欄（1行）
- ✅ テキスト入力欄（複数行）
- ✅ タイムスタンプボタン（yyyy/mm/dd hh:mm形式で日時を挿入）
- ✅ コピーボタン（タイトル + テキストをクリップボードにコピー）
- ✅ ダウンロードボタン（.txt / .md 形式を選択可能）
- ✅ ファイル名自動生成（日付_タイトル形式）
- ✅ クリアボタン（確認ダイアログなしで即座にクリア）
- ✅ 文字数カウント表示
- ✅ 行数カウント表示
- ✅ ローカルストレージによる自動保存
- ✅ レスポンシブデザイン（モバイル対応）
- ✅ 通知メッセージ表示

## 🚀 機能エントリポイント

### メインページ
- **URI**: `index.html`
- **説明**: メモ帳のメインインターフェース

### 主な機能

1. **タイトル入力**
   - 1行のテキスト入力欄
   - 自動保存機能付き

2. **テキスト入力**
   - 複数行のテキストエリア
   - リサイズ可能
   - 自動保存機能付き
   - タイムスタンプボタンでカーソル位置に日時を挿入（yyyy/mm/dd hh:mm形式）

3. **コピー機能**
   - タイトルとテキストをまとめてクリップボードにコピー
   - 成功時に通知表示

4. **ダウンロード機能**
   - ファイル形式選択（.txt / .md）
   - ファイル名自動生成（yyyymmdd_タイトル.拡張子）
   - Markdown形式の場合、タイトルを「# タイトル」として保存
   - タイトルがない場合は「yyyymmdd_memo」として保存

5. **クリア機能**
   - タイトルとテキストの両方を即座にクリア
   - 確認ダイアログなし

6. **統計表示**
   - リアルタイム文字数カウント
   - リアルタイム行数カウント

7. **自動保存**
   - ブラウザのローカルストレージに自動保存
   - ページをリロードしてもデータが保持される

## 💾 データストレージ

- **使用技術**: localStorage API
- **保存キー**:
  - `notepad_title`: タイトルの内容
  - `notepad_content`: テキストの内容
- **自動保存**: 入力内容の変更時に自動的に保存
- **データ永続化**: ブラウザを閉じても内容が保持される

## 📝 使い方

### 基本操作

1. **アプリを開く**
   - Webアプリ集のトップページから「ブラウザメモ帳」をクリック
   - または直接 `simplenotepad/index.html` をブラウザで開く

2. **メモを作成**
   - タイトル欄にタイトルを入力（省略可）
   - テキスト欄にメモを入力

3. **タイムスタンプを挿入**
   - 「🕒 タイムスタンプ」ボタンをクリック
   - カーソル位置に現在日時が挿入される（yyyy/mm/dd hh:mm形式）

4. **統計情報を確認**
   - 文字数と行数がリアルタイムで表示される

5. **データをコピー**
   - 「📋 コピー」ボタンでタイトル+テキストをクリップボードにコピー
   - 成功時に通知が表示される

6. **ファイルとして保存**
   - 形式を選択（.txt または .md）
   - 「💾 ダウンロード」ボタンでファイル保存
   - ファイル名は「yyyymmdd_タイトル.拡張子」形式で自動生成
   - タイトルがない場合は「yyyymmdd_memo」となる

7. **内容をクリア**
   - 「🗑️ クリア」ボタンで即座に全内容を削除
   - 確認ダイアログは表示されない

8. **自動保存**
   - 入力内容は自動的にブラウザに保存される
   - ページをリロードしても内容が復元される

### ファイル形式の違い

- **.txt形式**: プレーンテキストとして保存
  ```
  タイトル
  
  テキスト内容...
  ```

- **.md形式**: Markdown形式で保存
  ```markdown
  # タイトル
  
  テキスト内容...
  ```

## 🔒 プライバシーとセキュリティ

- **ローカル保存**: すべてのデータはブラウザのローカルストレージに保存
- **サーバー送信なし**: データは外部に送信されない
- **オフライン動作**: インターネット接続不要で動作
- **ファイル名のサニタイズ**: 不正な文字を自動的に置換
