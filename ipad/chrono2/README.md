# Chrono Panel

高級感のあるクロノグラフ風デジタル＋アナログ時計表示と、年・月・日の時間経過を可視化するプログレスメーターを組み合わせたWebアプリケーションです。

## 🎯 プロジェクト概要

Chrono Panelは、時計機能とプログレス表示を統合した美しいダッシュボードです。計器盤のような質感と洗練されたUIで、時間の流れを視覚的に表現します。

## ✨ 実装済み機能

### 1. **アナログ時計ディスプレイ**
- **メインダイヤル**: 高級時計風のベゼルデザイン
- **時針・分針**: スムーズに動くアナログ針
- **サブダイヤル**: クロノグラフ風の秒針表示
- **目盛り**: 60分割の外周目盛り（5分ごとに強調表示）

### 2. **デジタル時刻表示**
- 12時間制（午前/午後表示）
- 日付表示（和暦形式：年月日（曜日））
- リアルタイム更新

### 3. **プログレスメーター**
- **YEAR（年間進捗）**: 
  - 1年の経過日数/残り日数
  - リアルタイムパーセンテージバー
- **MONTH（月間進捗）**: 
  - 当月の経過日数/残り日数
  - 月ごとの日数に対応
- **DAY（1日の進捗）**: 
  - 経過時刻/残り時刻（HH:MM形式）
  - 1日の時間経過を可視化

### 4. **レスポンシブデザイン**
- iPad向けに最適化された段階的レイアウト調整
- 画面サイズに応じた要素のスケーリング
- モバイルブラウザ対応（タップハイライト無効化、ユーザー選択無効化）

### 5. **視覚効果**
- グレイン（粒子）テクスチャ
- ビネット（周辺減光）効果
- ラジアルグラデーション背景
- ガラス質感のベゼル表現
- 発光感のあるシャドウ効果

## 🎨 デザイン特徴

- **カラースキーム**: ダークテーマ（ブラック＆ホワイト）
- **質感**: 計器盤、高級時計をイメージした金属的な仕上げ
- **アニメーション**: 針のスムーズな回転、プログレスバーの連続更新
- **フォント**: Apple Systemフォント（iOS/macOS最適化）

## 📊 主要機能の詳細

### 時刻表示ロジック
- **更新頻度**: 1秒ごと（ミリ秒単位で次の秒への同期）
- **時針角度**: `(時 % 12 + 分/60 + 秒/3600) × 30°`
- **分針角度**: `(分 + 秒/60) × 6°`
- **秒針角度**: `(秒 / 60) × 360°`

### プログレス計算
- **年間**: 1月1日 00:00 〜 12月31日 23:59
- **月間**: 当月1日 00:00 〜 月末 23:59
- **日間**: 当日 00:00 〜 23:59

### レスポンシブブレークポイント
- `max-width: 1024px`: ダイヤルサイズ 520px → 500px
- `max-width: 900px`: ダイヤルサイズ 500px → 460px

## 🌟 特筆すべき実装

1. **動的サイズ調整**: ウィンドウリサイズ時に目盛りと針のサイズを再計算
2. **閏年対応**: 年間日数を自動計算（365日 or 366日）
3. **月末日対応**: 各月の日数（28/29/30/31日）に自動対応
4. **アンチエイリアシング**: iOS Safariでのテキスト表示最適化
5. **パフォーマンス**: requestAnimationFrameではなくsetTimeoutで秒単位の正確な更新
