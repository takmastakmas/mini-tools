# 1440 Tiles Clock

1日24時間を1440個のタイルで視覚化する、ユニークなWebアプリケーションです。時間の経過を直感的に感じることができます。

## 🎯 プロジェクト概要

画面全体に24行×60列のグリッドを描画し、1日の1440分を一つ一つのタイルに対応させます。経過した時間は枠線のみのタイル（□）で、まだ訪れていない時間は塗りつぶされたタイル（■）で表現されます。

## ✨ 主な機能

- **1440タイルグリッド**:
  - 1日（24時間×60分）を1440個のタイルで表現
  - 経過した分は暗い枠線で、未来の分は明るい塗りで表示
- **デジタル時計**:
  - 画面中央に現在の時刻を12時間形式（H:MM AM/PM）で表示
- **Canvasによる描画**:
  - HTML5 Canvas APIを使用してグリッドを効率的に描画
- **レスポンシブデザイン**:
  - ウィンドウサイズに合わせて、表示されるタイルの大きさが動的に変更されます
  - 高解像度ディスプレイ（Retinaなど）でも鮮明に表示されるよう、`devicePixelRatio`を考慮
- **パフォーマンス最適化**:
  - 1分ごとに画面を更新
  - ページが非表示状態から復帰した際に、表示を即座に同期

## 🚀 使い方

`index.html`をブラウザで開くと、現在の時刻に基づいたタイル時計が表示されます。

## 📁 ファイル構成

```
.
└── index.html    # アプリケーション本体 (HTML, CSS, JS統合)
```

## 🔧 技術仕様

- **HTML5**: Canvas要素と`apple-mobile-web-app-capable`メタタグ
- **CSS**: インラインCSSによる基本的なレイアウト
- **JavaScript (ES5)**:
  - ライブラリ不要
  - Canvas APIによる描画ロジック
  - `devicePixelRatio`を利用した高DPI対応
  - `setTimeout`と`visibilitychange`イベントによる効率的な更新処理
