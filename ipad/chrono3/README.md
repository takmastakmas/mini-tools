# Chrono Panel

クロノグラフ風の高級感あるダッシュボードアプリケーション。iPad/タブレット向けに最適化された計器盤スタイルのUIで、時刻表示と時間の進捗を可視化します。

## 📱 プロジェクト概要

Chrono Panelは、腕時計のクロノグラフをモチーフにした美しいタイムダッシュボードです。アナログ時計の視覚的な美しさと、デジタル情報の実用性を組み合わせた、洗練されたインターフェースを提供します。

## ✨ 主な機能

### 完成している機能

1. **アナログ時計ダイヤル（左側）**
   - 高級感のある計器盤デザイン
   - 時針・分針のアナログ表示
   - 60個の目盛りマーク（5分刻みで太い目盛り）
   - サブダイヤル（秒針表示）
   - リアルタイムで滑らかに動作

2. **デジタル時刻表示（中央）**
   - 大きな文字で視認性の高い時刻表示（12時間制、午前/午後表示）
   - 日付表示（年月日、曜日）
   - 日本語フォーマット

3. **プログレスメーター（右側）**
   - **YEAR（年間進捗）**: 今年が何％進んだかを表示
     - 経過日数と残り日数を表示
   - **MONTH（月間進捗）**: 今月が何％進んだかを表示
     - 経過日数と残り日数を表示
   - **DAY（日間進捗）**: 今日が何％進んだかを表示
     - 経過時間と残り時間を表示（HH:MM形式）
   - 各メーターにはグラデーション効果と細かい目盛り表示

4. **視覚エフェクト**
   - ラジアルグラデーション背景
   - ビネット効果（周辺減光）
   - グレイン（粒状感）テクスチャ
   - ガラスのような質感のベゼル
   - シャドウとグロー効果

5. **レスポンシブデザイン**
   - iPad向けに最適化（1024px以下、900px以下で段階的調整）
   - 画面サイズに応じた自動リサイズ
   - タッチデバイス対応（-webkit-最適化）

### UIコンポーネント

- **#dial**: メインダイヤル（アナログ時計）
- **#readout**: 中央のデジタル表示部
- **#right**: 右側のプログレスメーターパネル
- **#sub**: サブダイヤル（秒針）

## 🛠️ 技術仕様

- **言語**: HTML5, CSS3, JavaScript（Vanilla JS）
- **対応デバイス**: iPad, タブレット（推奨: 横向き）
- **ブラウザ要件**: WebKit対応ブラウザ（Safari推奨）
- **特殊機能**:
  - `-webkit-` プレフィックス使用（iOS最適化）
  - `requestAnimationFrame`の代わりに`setTimeout`で秒単位更新
  - リサイズイベントでのダイヤル再描画

## 📊 データ構造

このアプリケーションは外部データを使用せず、JavaScriptの`Date`オブジェクトからリアルタイムで時間情報を取得します。

## 🚀 使用方法

1. **起動**: `ipad_chrono.html`をブラウザで開く
2. **自動実行**: ページを開くと自動的にアニメーションが開始
3. **リアルタイム更新**: 1秒ごとに自動更新（ミリ秒単位で同期）

### 推奨環境

- **デバイス**: iPad（第1世代以降）、タブレット
- **画面向き**: 横向き（Landscape）
- **解像度**: 1024×768以上
