# Chrono Panel v1

計器盤をモチーフにした、多機能なタイムダッシュボード・アプリケーションです。アナログ時計、デジタル時計、そして年・月・日の進捗メーターを統合して表示します。

## 🎯 プロジェクト概要

左側にアナログ時計、右側に各種プログレスメーターを配置したダッシュボードです。時間の経過を複数の視点から直感的に把握することができます。

## ✨ 主な機能

- **アナログ時計**:
  - 時針と分針を持つ、リアルタイムで動作するアナログダイヤル
  - 5分ごとに強調された60個の目盛りを動的に生成
- **デジタル表示**:
  - アナログ時計の中央に、見やすいデジタル時刻（午前/午後 H:MM）と日付（年月日・曜日）を表示
- **プログレスメーター**:
  - **YEAR**: 年間の進捗率をパーセンテージで表示（経過日数と残り日数）
  - **MONTH**: 月間の進捗率をパーセンテージで表示（経過日数と残り日数）
  - **DAY**: 1日の経過時間をパーセンテージで表示（経過時間と残り時間）
- **UIデザイン**:
  - 計器盤風のダークなデザイン
  - グリッド、グラデーション、シャドウを多用したリッチな視覚効果
- **レスポンシブ対応**:
  - iPadの画面サイズ（1024px, 900px）に合わせてレイアウトを自動調整

## 🚀 使い方

`index.html`をブラウザで開くと、現在時刻に基づいたダッシュボードが表示されます。表示は1秒ごとに自動更新されます。

## 🔧 技術仕様

- **HTML5**: `apple-mobile-web-app-capable`メタタグによるiOSホーム画面対応
- **CSS**: インラインCSSによる複雑なレイアウトとスタイリング（グラデーション、シャドウ、レスポンシブ対応）
- **JavaScript (ES5)**: ライブラリ不要。時刻計算、プログレスバーの計算、アナログ時計の動的描画など、すべてのロジックを管理します。
