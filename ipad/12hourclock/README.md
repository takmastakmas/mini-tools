# 12時間表示時計

初代iPad（iOS 5以前）のSafariでも動作するように設計された、シンプルな12時間表示の時計アプリケーションです。

## 🎯 プロジェクト概要

黒い背景に白い文字で、現在の時刻を「午前/午後 H時MM分」の形式で大きく表示します。古いデバイスでのパフォーマンスを考慮し、軽量な作りになっています。

## ✨ 主な機能

- **12時間表示**: 午前/午後を漢字で表示
- **分単位更新**: 1分ごとに時刻が更新されます
- **レスポンシブデザイン**: 画面幅に応じてフォントサイズが自動調整されます
- **フルスクリーン対応**: iOSのホーム画面に追加してWebアプリとして利用可能
- **旧ブラウザ対応**: ES5以前のJavaScriptで記述されており、古いブラウザでも動作します

## 🚀 使い方

`index.html`をブラウザで開くだけで、現在の時刻が表示されます。

## 📁 ファイル構成

```
.
└── index.html    # アプリケーション本体 (HTML, CSS, JS統合)
```

## 🔧 技術仕様

- **HTML5**: `apple-mobile-web-app-capable`メタタグによるiOSホーム画面対応
- **CSS**: インラインCSSによる基本的なスタイリング
- **JavaScript (ES5)**: ライブラリ不要のシンプルな時刻更新ロジック
