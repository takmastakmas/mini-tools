# 日付表示

現在の日付と曜日を大きく表示することに特化した、シンプルなWebアプリケーションです。初代iPadなど、古いデバイスでも軽快に動作するように作られています。

## 🎯 プロジェクト概要

黒い背景に白い大きな文字で、現在の日付を「月日（曜日）」の形式で表示します。余計な機能を一切省き、日付の確認という一点に集中したデザインです。

## ✨ 主な機能

- **日付と曜日の表示**: 「M月D日（曜日）」の形式で表示
- **分単位更新**: 日付が変わる深夜0時をまたいでも自動で表示が更新されます
- **レスポンシブデザイン**: 画面幅に応じてフォントサイズが自動調整されます
- **フルスクリーン対応**: iOSのホーム画面に追加してWebアプリとして利用可能
- **カスタマイズ可能**: コード内のフラグ（`SHOW_YEAR`）を`true`に変更することで、西暦を含めた表示（例: 2026年1月1日（木））に切り替え可能です

## 🚀 使い方

`index.html`をブラウザで開くだけで、現在の日付が表示されます。

## 🔧 技術仕様

- **HTML5**: `apple-mobile-web-app-capable`メタタグによるiOSホーム画面対応
- **CSS**: インラインCSSによる基本的なスタイリング
- **JavaScript (ES5)**: ライブラリ不要のシンプルな日付更新ロジック
