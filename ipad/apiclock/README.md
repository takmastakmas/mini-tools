# 現在時刻表示サイト（API時刻対応版）

初代iPad Safari対応のシンプルな現在時刻表示Webサイト

## プロジェクト概要

現在時刻を大きく見やすく表示するシンプルなWebサイトです。初代iPad（iOS 3.2-5.x）のSafariでも正しく動作するよう、古いブラウザ互換性を重視して開発されています。

**WorldTimeAPI**を使用してインターネット上の正確な時刻を取得し、デバイスの時刻設定に依存しない正確な時刻表示を実現しています。

## 主な特徴

- **正確な時刻取得**: WorldTimeAPIから日本時間（Asia/Tokyo）を取得
- **自動フォールバック**: API接続失敗時は自動的にローカル時刻を使用
- **定期的な同期**: 1時間ごとにAPIと再同期して時刻のズレを補正
- **大きく見やすい時刻表示**: 時:分を80pxの大きなフォントで表示
- **日付と曜日表示**: 年月日と曜日も表示
- **リアルタイム更新**: 1分ごとに自動更新
- **古いブラウザ対応**: ES5以前のJavaScript構文を使用
- **レスポンシブデザイン**: iPadの縦向き・横向き両対応
- **シンプルなデザイン**: 黒背景に白文字で見やすく

## 技術仕様

### 時刻取得の仕組み

1. **初回読み込み**: まずローカル時刻で即座に表示
2. **API同期**: WorldTimeAPIから正確な日本時間を非同期で取得
3. **オフセット計算**: API時刻とローカル時刻の差分を計算し保持
4. **以降の表示**: ローカル時刻にオフセットを適用してAPI時刻を再現
5. **定期再同期**: 1時間ごとにAPIと再同期して精度を維持
6. **フォールバック**: API接続失敗時は自動的にローカル時刻を使用

### 使用API

- **WorldTimeAPI**: https://worldtimeapi.org/api/timezone/Asia/Tokyo
  - 無料・認証不要・CORS対応
  - タイムゾーン: Asia/Tokyo（日本時間）
  - 接続タイムアウト: 5秒

### 互換性のための制限事項

以下の新しい技術は使用せず、古いブラウザでも動作するようにしています：

- ❌ ES6構文（const/let、アロー関数、テンプレートリテラルなど）
- ❌ Flexbox、Grid Layout
- ❌ 高度なCSS3機能
- ✅ ES5以前のJavaScript（XMLHttpRequest使用）
- ✅ 基本的なCSS2/CSS3（text-shadow、media queryなど）
- ✅ var、function構文
