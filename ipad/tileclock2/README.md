# 1440 Tiles Clock v2

1日の時間を1440個のタイルで可視化するWebアプリケーションの、別スタイルバージョンです。

## 🎯 プロジェクト概要

基本的な機能はオリジナルの`tileclock`と同じですが、より落ち着いた、ミニマルなデザインに変更されています。経過した時間（□）と未来の時間（■）の対比がより穏やかになり、中央のデジタル時計が際立つよう調整されています。

## ✨ 主な機能

- **1440タイルグリッド**: 1日の1440分をタイルで表現
  - **スタイル変更**: オリジナル版より彩度を落とした、落ち着いた色のタイル
- **デジタル時計**: 中央に12時間形式（H:MM AM/PM）で時刻を表示
- **Canvasによる描画**: HTML5 Canvas APIによる効率的な描画
- **レスポンシブデザイン**: ウィンドウサイズに合わせた動的なタイルサイズ調整
- **パフォーマンス最適化**: 1分ごとの更新と、ページ復帰時の表示同期

## 🚀 使い方

`index.html`をブラウザで開くと、現在の時刻に基づいたタイル時計が表示されます。

## 📁 ファイル構成

```
.
└── index.html    # アプリケーション本体 (HTML, CSS, JS統合)
```

## 🔧 技術仕様

- **HTML5**: Canvas要素と`apple-mobile-web-app-capable`メタタグ
- **CSS**: インラインCSSによる基本的なレイアウト
- **JavaScript (ES5)**:
  - ライブラリ不要
  - Canvas APIによる描画ロジック
  - `devicePixelRatio`を利用した高DPI対応
  - `setTimeout`と`visibilitychange`イベントによる効率的な更新処理
