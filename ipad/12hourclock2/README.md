# 現在時刻表示サイト

初代iPad Safari対応のシンプルな現在時刻表示Webサイト

## プロジェクト概要

現在時刻を大きく見やすく表示するシンプルなWebサイトです。初代iPad（iOS 3.2-5.x）のSafariでも正しく動作するよう、古いブラウザ互換性を重視して開発されています。

## 主な特徴

- **大きく見やすい時刻表示**: 12時間表示で時:分を大きなフォントで表示
- **午前/午後をアイコンで表示**: ☀（太陽）= 午前、🌙（月）= 午後
- **日付と曜日表示**: 年月日と曜日も表示
- **リアルタイム更新**: 1分ごとに自動更新
- **古いブラウザ対応**: ES5以前のJavaScript構文を使用
- **レスポンシブデザイン**: iPadの縦向き・横向き両対応
- **シンプルなデザイン**: 黒背景に白文字で見やすく

## 技術仕様

### 互換性のための制限事項

以下の新しい技術は使用せず、古いブラウザでも動作するようにしています：

- ❌ ES6構文（const/let、アロー関数、テンプレートリテラルなど）
- ❌ Flexbox、Grid Layout
- ❌ 高度なCSS3機能
- ✅ ES5以前のJavaScript
- ✅ 基本的なCSS2/CSS3（text-shadow、media queryなど）
- ✅ var、function構文

### ファイル構成

```
├── index.html          # メインHTMLファイル
├── css/
│   └── style.css      # スタイルシート（古いCSS構文）
├── js/
│   └── clock.js       # 時刻更新ロジック（ES5以前の構文）
└── README.md          # このファイル
```

## 実装済み機能

- ✅ 現在時刻の12時間表示（時:分）
- ✅ 午前/午後をアイコンで表示（☀ 太陽 = 午前、🌙 月 = 午後）
- ✅ 現在日付の表示（年月日・曜日）
- ✅ 1分ごとの自動更新
- ✅ レスポンシブレイアウト
- ✅ 初代iPad Safari対応
- ✅ 黒背景に白文字のシンプルデザイン

## 動作確認環境

- 初代iPad Safari (iOS 3.2-5.x)
- モダンブラウザ全般でも動作確認済み

## 使用方法

index.htmlをブラウザで開くだけで使用できます。サーバー不要で動作します。
