## 📂 ファイル一覧（読む順序付き）

### 初めてこのプロジェクトに触れる場合
```
1. README.md                      ← まずここから
2. PROJECT_GUIDE.md               ← 全体像を深く理解
3. DEVELOPMENT_GUIDELINES.md      ← 開発する場合は必読
4. QUICK_REFERENCE.md             ← 開発中に参照
```

### コードを書く前
```
1. DEVELOPMENT_GUIDELINES.md      ← 必須パターンを理解
2. QUICK_REFERENCE.md             ← スニペットを確認
3. 既存のコード（index.html, css/style.css） ← 実装例を参照
```

### なぜこうなっているか理解したい場合
```
1. README.md                      ← 概要を把握
2. PROJECT_GUIDE.md               ← 技術的背景とビジュアル比較を確認
3. css/style-original.css         ← 元のCSSを参照
```

## 🎯 状況別ガイド

### ケース1: 新しい時計アプリを追加したい
```
□ 1. DEVELOPMENT_GUIDELINES.md を読む
□ 2. 使用禁止技術リストを確認
□ 3. QUICK_REFERENCE.md のスニペットを使用
□ 4. 既存のコード（index.html）を参考にする
□ 5. コードレビューチェックリストで確認
□ 6. 初代iPadシミュレータでテスト
□ 7. デプロイ前チェックリストを確認
```

### ケース2: 既存コードを修正したい
```
□ 1. DEVELOPMENT_GUIDELINES.md の該当セクションを確認
□ 2. 変更がガイドラインに準拠しているか確認
□ 3. QUICK_REFERENCE.md で正しい書き方を確認
□ 4. 変更後にテスト
```

### ケース3: なぜこのコードなのか理解したい
```
□ 1. PROJECT_GUIDE.md の「技術的な変換の詳細」を読む
□ 2. PROJECT_GUIDE.md の「ビジュアル比較」で元デザインを確認
□ 3. css/style-original.css と css/style.css を比較
```

### ケース4: デバッグしたい
```
□ 1. DEVELOPMENT_GUIDELINES.md の「よくあるエラー」を確認
□ 2. QUICK_REFERENCE.md の「よくある間違い」を確認
□ 3. ブラウザのコンソールでエラーメッセージを確認
□ 4. 使用禁止技術を使っていないか確認
```

### ケース5: 使い方を知りたい
```
□ 1. PROJECT_GUIDE.md の「使い方ガイド」を読む
□ 2. 動作確認項目をチェック
□ 3. よくある質問を確認
```

## 📞 サポート・質問

### よくある質問の答え

**Q: どこから読み始めればいい？**  
A: **README.md** → **PROJECT_GUIDE.md** → **DEVELOPMENT_GUIDELINES.md** の順番で読んでください。

**Q: コードを書く前に何を確認すべき？**  
A: **DEVELOPMENT_GUIDELINES.md** の使用禁止技術リストと必須パターンを確認してください。

**Q: 開発中に困ったら？**  
A: **QUICK_REFERENCE.md** のスニペットとよくある間違いを参照してください。

**Q: なぜこのような実装になっているの？**  
A: **PROJECT_GUIDE.md** の「技術的な変換の詳細」で説明しています。

**Q: デザインは本当に同じ？**  
A: **PROJECT_GUIDE.md** の「ビジュアル比較」で完全一致を確認できます。

**Q: 使い方を知りたい**  
A: **PROJECT_GUIDE.md** の「使い方ガイド」を読んでください。
