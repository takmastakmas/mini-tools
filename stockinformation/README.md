# 株式リンクジェネレーター

銘柄コードを入力するだけで、四季報、Yahoo!ファイナンス、みんかぶ、株探、株マップ、Ullet、株予報proへのリンクを即座に生成するシンプルなWebツールです。

## 🎯 プロジェクト概要

日本株の銘柄コード（4桁）を入力して実行ボタンを押すと、7つの主要な投資情報サイトへ直接アクセスできるリンクが一括生成されます。

## ✨ 実装済み機能

### 1. 銘柄コード入力
- **4桁の銘柄コード入力**: 数字のみ受け付け（自動フィルタリング）
- **入力検証**: 4桁以外の入力はエラー表示
- **Enterキー対応**: キーボードだけで操作可能

### 2. リンク生成機能
- **四季報リンク**: 会社四季報の詳細企業情報へアクセス
- **Yahoo!ファイナンスリンク**: 株価、チャート、ニュース、財務情報へアクセス
- **みんかぶリンク**: 株価予想、アナリスト評価、掲示板へアクセス
- **株探（決算）リンク**: 決算情報、業績予想、財務分析へアクセス
- **株マップリンク**: テクニカル分析、チャートパターン、指標分析を確認
- **Ulletリンク**: 企業の詳細財務データと業績推移を確認
- **株予報proリンク**: AIによる株価予測と詳細レポートへアクセス
- **新しいタブで開く**: すべてのリンクは別タブで表示

### 3. ユーザーインターフェース
- **シンプルデザイン**: 必要最小限の機能に特化
- **レスポンシブ対応**: PC、タブレット、スマートフォンで快適に使用可能
- **モダンなUI**: グラデーション背景とアニメーション効果
- **7つのリンクボタン**: 各サイトごとに色分けされた見やすいボタン配置
- **例示ボタン**: よく使われる銘柄コードをワンクリックで入力

### 4. キーボードショートカット
- **Ctrl+K / Cmd+K**: 入力ボックスにフォーカス＆選択
- **Enter**: 実行ボタンを押す

### 5. アニメーション効果
- **スライドアップアニメーション**: 結果表示時
- **スムーズスクロール**: 結果セクションへ自動スクロール
- **ホバーエフェクト**: ボタンとリンクに視覚的フィードバック

## 🚀 使い方

### 基本的な使用方法
1. **銘柄コードを入力**: 検索したい銘柄の4桁コードを入力（例: 7203）
2. **実行ボタンをクリック**: または Enterキー を押す
3. **リンクをクリック**: 四季報、Yahoo!ファイナンス、みんかぶ、株探、株マップ、Ullet、株予報proのいずれかのボタンをクリックして情報を確認

### 履歴機能の使い方
- 一度検索した銘柄コードは自動的に履歴に保存されます
- 入力ボックスの下に「履歴：」セクションが表示されます
- 履歴ボタンをクリックすると、その銘柄を再検索できます
- 最新5件までの履歴が保持されます（古いものは自動削除）
- ブラウザを閉じても履歴は保持されます（LocalStorage使用）

## 🌐 生成されるリンクURL形式

### 四季報
- **形式**: `https://shikiho.toyokeizai.net/stocks/{銘柄コード}`
- **例**: `https://shikiho.toyokeizai.net/stocks/7203`（トヨタ自動車）
- **提供情報**: 会社四季報の詳細企業情報、業績予想、アナリストコメントなど

### Yahoo!ファイナンス
- **形式**: `https://finance.yahoo.co.jp/quote/{銘柄コード}.T`
- **例**: `https://finance.yahoo.co.jp/quote/7203.T`（トヨタ自動車）
- **提供情報**: 株価、チャート、ニュース、財務情報、企業概要など

### みんかぶ
- **形式**: `https://minkabu.jp/stock/{銘柄コード}`
- **例**: `https://minkabu.jp/stock/7203`（トヨタ自動車）
- **提供情報**: 株価予想、アナリスト評価、掲示板、ニュースなど

### 株探（決算）
- **形式**: `https://kabutan.jp/stock/finance?code={銘柄コード}`
- **例**: `https://kabutan.jp/stock/finance?code=7203`（トヨタ自動車）
- **提供情報**: 決算情報、業績予想、財務分析、決算短信など

### 株マップ
- **形式**: `https://jp.kabumap.com/servlets/kabumap/Action?SRC=techBunseki/base&codetext={銘柄コード}`
- **例**: `https://jp.kabumap.com/servlets/kabumap/Action?SRC=techBunseki/base&codetext=7203`（トヨタ自動車）
- **提供情報**: テクニカル分析、チャートパターン、各種テクニカル指標など

### Ullet
- **形式**: `https://www.ullet.com/{銘柄コード}.html`
- **例**: `https://www.ullet.com/7203.html`（トヨタ自動車）
- **提供情報**: 詳細財務データ、業績推移、株主構成、関連企業など

### 株予報pro
- **形式**: `https://kabuyoho.jp/reportTop?bcode={銘柄コード}`
- **例**: `https://kabuyoho.jp/reportTop?bcode=7203`（トヨタ自動車）
- **提供情報**: AIによる株価予測、詳細分析レポート、テクニカル分析など

## ⚠️ 制限事項

### 実装されていない機能
1. **企業名表示**: 
   - 銘柄コードから企業名を自動取得する機能はありません
   - リンク先のYahoo!ファイナンスやみんかぶで企業名を確認できます

2. **リアルタイム株価表示**: 
   - 株価データの取得・表示は実装していません
   - リンク先で最新の株価情報を確認できます

3. **チャート表示**: 
   - チャート機能は実装していません

4. **お気に入り機能**: 
   - 現在は未実装

5. **履歴機能**: 
   - 検索履歴の保存機能は未実装

### 入力制限
- **4桁の数字のみ**: 銘柄コードは4桁固定です
- **日本株のみ**: 東証上場銘柄を想定しています
