# Zoom表示名ジェネレーター

Zoomミーティングに好きな表示名で参加できるリンクを簡単に生成するWebアプリケーションです。

## 🎯 プロジェクトの目的

Zoomミーティングに参加する際、事前に表示名を指定したリンクを生成することで、入室時の名前変更の手間を省きます。

## ✨ 主な機能

### 現在実装されている機能

1. **Zoomリンク入力**
   - Zoomミーティングの招待URLを貼り付け
   - URL形式の簡易バリデーション

2. **表示名入力**
   - 任意の表示名を指定
   - 日本語・英語・記号に対応

3. **リンク生成**
   - `uname`パラメータを追加したリンクを自動生成
   - URLエンコード処理を実行

4. **履歴機能**
   - 過去に使用した表示名を最大5件保存
   - ワンクリックで再利用可能
   - 履歴のクリア機能

5. **クリップボードコピー**
   - ワンクリックでリンクをコピー
   - コピー成功メッセージを表示

6. **すぐに入室**
   - 生成されたリンクで新しいタブでZoomを開く

7. **トースト通知**
   - 成功・エラー・警告・情報の4種類の通知
   - 非侵襲的なユーザー体験

## 🚀 使い方

1. **index.html**をブラウザで開く
2. Zoomミーティングの招待リンクを「Zoomミーティングのアドレス」フィールドに貼り付け
3. 表示したい名前を「表示名」フィールドに入力
4. 「リンクを生成」ボタンをクリック
5. 生成されたリンクを「リンクをコピー」でコピー、または「すぐに入室」で直接参加

### Enterキーでの操作

- 各入力フィールドで`Enter`キーを押すとリンクを生成できます

### 履歴機能

- 過去に使用した表示名が自動的に保存されます
- 履歴ボタンをクリックすると、その名前が入力フィールドに自動入力されます
- 「履歴をクリア」ボタンですべての履歴を削除できます

## 🏗️ アーキテクチャ

### クラスベース設計

このアプリは`ZoomLinkGeneratorApp`クラスを使用したモダンな設計を採用しています。

```javascript
class ZoomLinkGeneratorApp {
    constructor() {
        this.storageKey = 'zoomDisplayNameHistory';
        this.maxHistory = 5;
        this.elements = {};
        this.init();
    }
    
    init() {
        this.initElements();       // DOM要素の取得
        this.renderHistory();      // 履歴の表示
        this.attachEventListeners(); // イベント設定
    }
    
    // ... 他のメソッド
}
```

### 主要な機能

| メソッド | 説明 |
|---------|------|
| `generateZoomLink()` | Zoomリンクを生成 |
| `copyToClipboard()` | クリップボードにコピー |
| `joinZoom()` | 新しいタブでZoomを開く |
| `loadHistory()` | 履歴を読み込み |
| `saveHistory()` | 履歴を保存 |
| `addToHistory()` | 履歴に追加 |
| `renderHistory()` | 履歴を表示 |
| `clearHistory()` | 履歴をクリア |
| `showToast()` | トースト通知を表示 |
